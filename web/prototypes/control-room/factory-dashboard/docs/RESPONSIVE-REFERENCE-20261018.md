# 공장 반응형 시안 · 2026-10-18

사용자가 첨부한 한 장의 시안은 넓은 화면과 같은 웹의 좁은 화면이다. 별도 페이지나 이미지 전환으로 구현하지 않는다.

- 넓은 화면: 01~03 / 04~06의 3열 2행, 한 줄 헤더, 헤더 안의 현재 작업 열기 버튼.
- 좁은 화면: 01·02 / 03·04 / 05·06의 2열 3행, 하단의 접힌 현재 작업 버튼. 각 구역의 여섯 연결 길을 유지하고 중앙의 긴 수직 길을 만들지 않는다.
- 창 크기와 열린 상세 패널에 맞춰 카메라를 다시 맞춘다. 상세 패널 닫기·전체 화면으로·Escape 복귀 동작을 유지한다.
- 연구원·작업실 PNG 원본은 변경하지 않았다. 실행/선택 상태, Skill 판정, 기록·결과·재생, 실제 실행 수에 따른 확대 및 기존 모션 규칙을 유지한다.
- 화면 배치 변경만 포함한다. 업무 DB, 수집기, 하네스 실행기, 다른 저장소, 공개 Site는 변경하지 않는다.

## 검증 범위

Node 회귀 검사 189개 통과(exit 0). 1~6개 동시 실행의 모든 64가지 조합에서 원본 작업실 전체가 카메라에 포함되며 실행 상태와 크기를 보존하는 검사를 포함한다. 원본 연구원 PNG SHA-256 검사도 통과했다. Vite 일반 빌드와 단일 HTML 빌드를 실행했다(exit 0).

로컬 브라우저에서 1440×900, 754×768, 390×844 및 320×568 화면을 확인한다. 전체/좁은 화면의 접힌 기본 상태, 구역 선택 패널, 전체 화면 복귀 및 Escape를 확인했다. 모션 예시에서 두 구역(이동 연구원 2명·대기 4명), 세 구역(이동 3명·대기 3명)의 표시를 대조했다.

실제 설치된 하네스의 기존 관측을 읽는 연결은 유지한다. 이번 변경에서 새 모델 호출·업무 CLI 실행을 하지 않았으며, 모션 예시를 실제 CLI 인수 결과로 취급하지 않는다. 원문 실행 로그와 화면 증거는 Git 제외 경로에만 둔다.

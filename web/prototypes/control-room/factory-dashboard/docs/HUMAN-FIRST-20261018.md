# 기획자를 위한 작업 화면 정리

2026-10-18. AJ의 실제 기록 재생·Codex/Claude 화면 검토에서 합의한 표현을 반영한다.

- 기본 화면은 공장 시각화와 현재 업무 안내 한 곳, 열 수 있는 기획안 링크다. 왼쪽 CLI feed와 오른쪽 자동 작업 dock을 기본으로 펼치지 않는다. Skill 목록과 담당 AI·실행 기록의 접근 경로는 유지한다.
- 안내는 관측된 작업을 평문으로 설명한다. 조용한 구간에는 `메인 기획 AI가 작업하고 있어요`로 표현하고 설명서 조회와 실제 Skill 작업을 합치지 않는다. 알려지지 않은 퍼센트·남은 시간·분석 경계를 만들지 않는다.
- 정상 경로의 `돌아가기`가 합성 데모를 여는 기능을 제거했다. 합성 상품기획 예시와 동작 예시는 명시적으로 실행 도구 메뉴에서만 선택한다. 지난 실행 재생과 실제 작업의 표시는 구분한다.
- 연결 설정·버전·관측 기록 내보내기·원문 없는 사건 세부는 실행 도구 또는 명시 상세로 모은다. 관측기에 질문·답변·명령·추론 원문을 새로 수집하지 않는다.
- `기획안이 준비됐어요`는 현재 native 요청의 최종 종료, 열린 역할/호출 없음, DB의 현재 유효 결과와 구조 검사, 현재 업무 binding 및 result version과 viewer delivery의 일치, `display_ready`를 모두 확인한 경우에만 표시한다. `acceptance_ready`나 의미 검증 상태를 바꾸지 않는다.
- viewer delivery의 `report_data_ready`가 참일 때만 같은 기획안에서 보고서로 이어 볼 수 있다는 안내를 표시한다. HTML 파일 존재만으로 같은 결과라고 판정하지 않는다. 실제 viewer 전달 metadata의 생성·파일 점검은 visual-viewer 측에서 수행한다.
- 입력·승인 대기는 실제 DB/native 신호가 있을 때만 안내한다. 취소와 최종 실패를 구분한다. 한 Tool 오류나 관측 연결 단절을 전체 업무 실패로 바꾸지 않는다. 읽기에 실패해도 마지막 기록과 최근 기획안 접근을 보존한다.
- 요청이나 버전이 다르거나 저장 기록을 재생하는 경우 `최근 기획안 보기`로 표시한다. 이전 결과를 방금 요청의 성공 결과라고 부르지 않는다.

검사: `node --test tests/*.test.mjs` 173개 통과. 일반 Vite build와 office-mode build 성공. 이 검사는 합성 상태/연결 계약과 코드 빌드이며 새 native Agent 작업이나 실제 브라우저 육안 검사를 뜻하지 않는다. 생성된 factory.html의 최종 게시와 통합 화면 검수는 부모 통합 단계에서 수행한다.

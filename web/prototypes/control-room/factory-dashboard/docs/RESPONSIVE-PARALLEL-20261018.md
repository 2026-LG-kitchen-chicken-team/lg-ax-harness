# 두 개·세 개 Skill의 반응형 모션

전체 화면과 좁은 화면의 모션 시연도 실제 공장과 같은 3열 2행 / 2열 3행 배치를 사용한다. 기본 화면에 큰 작업 패널을 열지 않고, 필요한 정보와 시연 제어를 기존 현재 작업 버튼·메뉴 안에서 연다. 번호와 작업실 주소, 실제 실행 수에 따른 확대 비율 및 역할별 연구원 모션은 유지한다.

움직이는 카드·검사 효과는 연구원보다 뒤에 그려 얼굴을 가리지 않는다. 연구원과 작업실 PNG는 수정하지 않는다. 실제 Skill 판정·관측·기록·결과·재생 및 하네스 실행기는 변경하지 않는다.

- `?view=motion#parallel=2`: 두 구역의 모션 예시.
- `?view=motion#parallel=3`: 세 구역의 모션 예시.
- 같은 페이지에서 두 링크를 바꿔도 시연 개수가 바뀐다. 숫자는 화면 시연의 개수이며 실제 CLI 관측값이 아니다.
- 일시정지·재생, 시연 방식과 작업실 선택, 기존 영상 보기·기록, 상세 패널과 Escape 복귀를 유지한다.

## 검증 범위

여섯 뷰포트에서 두 개·세 개 조합 전체(15쌍·20삼중)의 확대 비율, 그림 영역 겹침과 카메라 포함을 검사한다. 작업 효과가 연구원 뒤에 그려지고 대기·동작 줄이기에서 시계가 진행하지 않는지도 검사한다. 기존 회귀 검사와 자산·단일 HTML 검사도 수행한다.

브라우저는 1440×900 및 390×844에서 두 개·세 개 예시를 대조하고, 메뉴·현재 작업 접기·일시정지/재생·창 크기 변경을 확인한다. 관측 데이터나 업무 DB를 생성하지 않는다. 이번 변경에서 실제 모델/업무 CLI를 새로 실행하지 않았으며, 시연을 실제 CLI 인수 결과로 설명하지 않는다. 화면 증거는 Git 제외 경로에 보존한다.

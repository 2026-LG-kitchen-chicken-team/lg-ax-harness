# 공장 모션 변경과 검증

2026-10-16 · KITCHEN AX · 기존 v10 보존본 이후 변경

- 실제 실행 상태에 따라 담당 공간이 축소 후 탄성 확대됩니다. 여러 공간은 동시에 펼치고 화면·열린 설명 패널 너비에 맞춰 배치합니다. 선택만으로 실행을 시작하지 않습니다.
- 연구원은 담당 구역 둘레를 순회한 뒤 자료를 확인합니다. 작업 중지·일시정지·동작 축소에서는 이동 시계를 멈춥니다. 생성한 contact/passing 두 포즈를 사용합니다.
- 유한한 바닥 판을 넓은 타일 필드로 바꾸고 나무·상자를 주변에 배치했습니다. 기본 전체 화면과 클릭 시 오른쪽 설명 패널을 유지합니다.
- 모션 미리보기에는 한 구역·동시 2/3/5구역 선택과 24초 영상 기록이 있습니다. 실제 CLI 실행·작업 기록과 분리된 시연입니다. 명시적인 녹화 중에만 별도 프레임 타이머를 사용합니다.

## 실제 검사

- Node 테스트 100/100 통과. 정상 분석·근거·릴리즈 관측의 기존 검사와 뷰포트/동선/전환 회귀를 포함합니다.
- Vite 프로덕션 빌드 통과. 기존 큰 번들 경고는 남아 있습니다.
- 독립 읽기 전용 검토에서 전환 중 겹침과 같은 보행 자세 두 건을 발견해 수정한 뒤 재검토를 통과했습니다. 검토자의 64 활성 조합 × 7 화면 조건, 81,088 전환 프레임 검사에서 플랫폼 교차 0건입니다.
- 브라우저: 1280×800 PC와 390×844 휴대폰에서 화면 넘침 없이 구역 이름 표시를 확인했습니다. 기본 화면의 좌/우/하단 고정 패널은 숨겨져 있고, 노드 선택 시에만 설명 패널이 열립니다.
- 실행이 확인 대기인 상태에서 다른 콘셉트 노드를 선택해도 실행 강조가 새로 생기지 않는 것을 확인했습니다.
- 실제 렌더링을 기록한 약 23.9초 MP4에서 두 연구원의 구역 순회를 확인했습니다. 영상은 public/media/researcher-motion-demo-v2.mp4 입니다.

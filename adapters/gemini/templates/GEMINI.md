# LG AX Gemini CLI 상품기획

@AGENTS.md

업무 Skill은 이 프로젝트의 `.gemini/skills/`다. 중복 발견을 피하려고 `.agents/skills/` 사본을 함께 설치하지 않는다. Skill 활성화 동의·폴더 신뢰·Tool 권한은 Gemini 안내에 따라 실행자가 선택한다.
Gemini 자신의 모델·Tool을 사용하고 Codex 또는 다른 모델을 내부 실행하지 않는다. 허용된 셸에서 Python wrapper를 호출한다. 프로젝트 지침은 실행 권한을 강제하지 않는다.
이 설치 사본의 native 발견·대화·보류·오류·사용량 검증은 아직 미완료다. 설정·권한·로그인을 자동 우회하지 않는다.

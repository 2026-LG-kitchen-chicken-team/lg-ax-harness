# LG AX 상품기획 에이전트

실제 후기와 공식 자료에서 사용 불편을 찾고, 기존 기능과 대조해 상품기획과 HTML 보고서로 정리하는 Codex·Claude Code용 하네스입니다. 이 저장소는 제품 배포 전용입니다.

## ZIP으로 시작하기

1. [제품 v0.19.0 시험판](https://github.com/2026-LG-kitchen-chicken-team/lg-ax-agent/releases/tag/product-v0.19.0)에서 **lg-ax-judge-product-v0.19.0.zip** 하나를 받습니다.
2. 새 폴더에 모두 압축을 풀고 맨 바깥의 **README.md 사용설명서**를 엽니다.
3. 사용할 Codex 또는 Claude의 시작 파일을 선택합니다. 로그인·작업 폴더·접근 승인은 사용설명서 순서대로 확인합니다.
4. 평소 말하듯 질문하고, 완료된 기획자 웹에서 핵심 기획을 읽습니다. 근거·부록은 필요할 때 열고, 같은 결과를 보고서로 볼 수 있습니다.

**터미널 한 줄 다운로드·자동 설치 명령과 AI에게 맡기는 원터치 설치 안내는 잠정 중단했습니다.** 이전 설치 도구·태그는 기록을 위해 보존하지만 현재 시작 방법으로 안내하지 않습니다.

ZIP 시작 파일은 계속 제공합니다. 현재 제품은 **uv와 Python 3.12 준비가 필요**하며, uv가 없으면 시작 파일에서 설치 여부를 묻습니다. 명령 안내 중단이 이 준비물을 제거했다는 뜻은 아닙니다. 자세한 준비·실패 시 조치는 ZIP의 사용설명서를 따릅니다. 이미 받은 ZIP은 GitHub CLI 설치나 개발 저장소 clone 없이 사용할 수 있습니다.

## 준비물과 결과

- 사용할 수 있는 Codex 또는 Claude Code 계정과 이용 한도, 인터넷, 브라우저가 필요합니다. 별도 모델 API key는 필요하지 않습니다.
- 일반 Chat 화면이 아니라 해당 실행기의 프로젝트/Code 환경에서 ZIP 안의 codex 또는 claude 폴더를 엽니다.
- 기본 보고서는 기획 내용만 먼저 보여줍니다. 원문·상세 비교는 근거 부록, 내부 JSON·지문·실행 기록은 고급 진단에 보관합니다. 기본 인쇄에는 전체 원문과 진단 기록을 넣지 않습니다.
- 결과 웹의 index.html과 view-data.js는 함께 보관합니다. 파일 하나로 공유하려면 보고서의 HTML 저장을 사용합니다.

## 업데이트와 접근

새 버전은 새 폴더에 풀어 사용하고 이전 결과·기록을 보관합니다. 자동 덮어쓰기나 DB 이전은 하지 않습니다. 받은 파일은 릴리즈의 SHA256SUMS.txt와 ZIP의 bundle-manifest.json으로 확인할 수 있습니다.

비공개 기간에는 저장소 읽기 권한 또는 이미 전달받은 ZIP이 필요합니다. 공개 전환 일정과 개발 저장소의 비공개 범위는 별도 결정대로 유지합니다. 원터치 안내 중단을 이유로 접근 정책·계정 설정을 변경하지 않습니다.

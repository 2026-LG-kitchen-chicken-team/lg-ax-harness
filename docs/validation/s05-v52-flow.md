# v5.2 최종 전달·반복·신규 입력 평가

2026-10-10. [이전 v5.1](s05-v51-flow.md)의 J17 양쪽420초 timeout을 보존하고, 저장 뒤 반복 출력과 거절 후보 복구를 개선했다. 자체 모델 API 실행기는 추가하지 않았다. 아래 runner는 개발 평가용이며 제품 ZIP에 들어가지 않는다.

## 변경과 범위

업무 Agent v5.2는 전체 결과/assessment를 실제 저장·export하되 Tool 반환은 선택 가능한 compact receipt와20개 상한의 findings, 최종 답변은 요약·실제 receipt/export 지문으로 전달한다. 기본 full 모드는 호환성을 유지했다. 이전 accepted 키 재생이 최신 후보를 뜻하지 않으므로 candidate/current 버전·최신 valid·handle/key/hash를 확인한다. 거절 원인을 구조적으로 수정하고 업무 수정 최대2회 뒤에는 근거에 맞게 보류한다. 반복 문자열 치환/큰 JSON 재작성 대신 구조화 JSON 작성을 안내한다.

JSON 파일/stdin은 UTF-8 BOM 및 명시적 UTF-16 BOM을 지원하고 크기·중복 키·비유한 수 검사를 유지한다. 임의 ANSI 추측은 하지 않는다. 이 변경은 팀원 payload 파일 오류를 줄이지만 AI가 직접 작성한 Python 스크립트의 잘못된 파일 decoding까지 대신 고치지는 않는다.

실제 실행은 Codex0.162.0·gpt-6.1-sol·ultra·Windows·never/danger-full-access, `--disable multi_agent`였다. 8개 입력, 각420초, 동시2개, 자동 재시도0을 사전에 제한했다. CLI 명령 반환과 rollout 관측을 보존하며 backend 전체 호출 수·청구·개발 사용량·사람 활동 시간은 미측정이다. 전8건 native 종료와 최종 agent_message가 관측됐고 각 프로세스 exit0이었다.

## 확인 범위

과거 실제 Codex GUI 메타데이터를 새 모델 호출 없이 재생하면 일반 Tool8·셸25의 총33호출(완료31·실패2)이 보존된다. 이 복합/간접 명령 기록은 명시 Skill로 추정하지 않아 Skill0이다. 처음에 Skill이 하나 이상이어야 한다고 둔 시험자의 예상은 해당 기록에 맞지 않았으며, 표시를 늘리기 위해 인식 범위를 풀지 않았다. 명시 단독 Skill 호출의 시작/종료·취소·실패는 별도 회귀 입력으로 검사했다. 새 실제 AI 업무·전 Skill 모션의 종단 간 인수와 구분한다.

이번 육안 확인은 데스크톱 served-dist다. 새 모바일·file:// 상호작용·전체 native 모션 인수를 주장하지 않는다. `factory-routing.js`의 경로 검사는 실제 FactoryScene 연결 완료 근거로 사용하지 않는다. 상위 UI 승인/스냅샷 문서는 당시 이력이며 이번 전체 인수는 이 문서의 새 검사를 따른다.

검토·병합은 개발 저장소의 main 통합 범위다. 기존 심사위원 릴리즈 ZIP이나 공개 Site를 자동 교체한 것으로 설명하지 않는다. 촬영·발표물 제작·새 모델 실행은0이다.

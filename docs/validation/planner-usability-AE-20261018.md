# 상품기획 결과 웹·보고서 사용성 개편

2026-10-18. 사용자 요청: 제안·기획 배경·다음 행동을 먼저 보여주고, 상세 조건·원문·개발 정보를 분리한다. 실제 저장 결과로 주요 화면을 캡처하고 로딩·갱신·오류 복구를 확인한다. 촬영·새 모델 업무 실행·제품 릴리스는 이 작업에 포함하지 않는다.

## 적용 내용

- 원질문·시험 지시·폴더 경로를 큰 제목으로 표시하던 표지를 업무 제목으로 바꿨다. 통계와 처리 흐름도보다 상품기획을 먼저 배치했다.
- 저장된 명시 제목을 표시하고, 없는 경우 저장 첫 문장을 그대로 강조한다. 화면을 위해 새 요약 모델을 호출하거나 제품별 제목·답안을 만들지 않는다.
- 제안에 기록된 남은 불편 연결만 기획 배경에 사용한다. 텍스트 유사성이나 같은 출처만으로 관계를 만들지 않는다.
- 다음 행동은 저장된 첫 적용 단계다. 전체 추진 조건·요구사항·실행 순서·검증 방법과 중복 판단은 제안 상세에서 읽는다. 추가 하드웨어·내부 치수가 필요한 경우는 카드에서 표시한다.
- 근거는 자료 목록에서 필요한 원문만 선택해 연다. 자료 종류·위치·외부 원문 URL을 유지한다.
- 보고서는 제안부터 시작하고 큰 문단 제목·중복 표지 요약·조사 메모 반복을 줄였다. 분석 판단은 사실/AI 해석/미확인 구분 및 출처 링크와 함께 부록에 남긴다.
- 유효·의미 검토·인수·파일 크기 등의 내부 표시를 일반 화면에서 분리했다. 보류·실패·취소·무효화·합성 근거 등 실제 적용에 영향을 주는 경고는 보존한다.
- 초기 HTML 준비 안내와 결과 읽기 중 스피너를 제공한다. 상태는 실제 읽기 상태이며 추정 AI 작업 단계나 가상 진행률이 아니다.

## 실제 확인

이전 실제 native 업무에서 저장된 냉장고·식기세척기·전자레인지 출력과 최신 별도 냉장고 출력을 새 공통 렌더러로 표시했다. 세 제품군의 기본 자료는 각각56·81·82개 등록 원문 객체이며, 최신 냉장고도56개다. 같은 자료를 추가로 합산해 독립 고객·새 조사 건수로 주장하지 않는다. 원본과 저장 export/출처 연결은 변경하지 않았다.

로컬 전용 읽기 서버의 새 빌드를 데스크톱 브라우저로 확인했다. 기존 `file://` 열기 거절을 성공으로 바꾸거나 기존 파일을 열었다고 기록하지 않는다.

| 경로 | 관측 결과 |
|---|---|
| 세 제품군 웹 → 보고서 | 각 제품군 제목·실제 기획 본문 표시, 정상 구간 JavaScript 오류 미관측 |
| 제안 → 추진 상세 → 근거 | 펼침, 자료별 원문 및 실제 원문 URL 확인 |
| 보고서 근거 번호 | 부록이 열리고 해당 원문 위치로 이동 |
| 데이터 없음 / 지연된 읽기 | 첫 결과 대기와 로딩 표시 구분 |
| 최초 읽기 실패 | 내부 HTTP 설명 대신 복구 안내와 다시 불러오기 제공 |
| 결과가 있는 상태에서 읽기 실패 | 기존 기획안 보존, 재시도 안내 표시 |
| 정상 자료 복구 | 실패 안내 해제 및 정상 결과 표시 |
| 보고서 열람 중 다른 저장 결과 수신 | 이전 보고서 안내·최신 보고서 전환 확인 |

대기·지연·HTTP503·결과 교체는 제어한 UI 시험이다. 새로운 native 조사나 실제 외부 서비스 장애가 아니다. 주요 화면 JPEG11장과 데이터가 포함된 단일 HTML4개를 사용자 로컬 검토 폴더에 저장했다. 원문·실행 로그·이미지는 이 문서나 Git에 포함하지 않는다.

## 검사와 범위

- 최종 웹 검사190개:189통과, Windows symlink 조건1제외, exit0.
- 프로덕션 빌드·단일 HTML 생성 exit0. 기존 잠금 의존성을 사용했고 새 패키지나 모델 제공사를 도입하지 않았다.
- 제품 자산 지문 검사 exit0. 제품 Agent·Skill·Tool·모델 기본값은 변경하지 않았다.
- 독립 읽기 검토에서 발견한 판단 메모의 출처 링크 누락과 하드웨어/치수 조건 누락을 수정했다. 실제 컴포넌트 회귀로 조건·전체 설명·이스케이프를 확인했다.
- 새 격리 checkout의 첫 전체 검사는 기존 office TypeScript 의존성이 없어1실패했다. 기존 설치 의존성을 연결한 후 최종190검사에 통과했다. 별도 빌드의 junction 의존성 열거 오류도 기존 의존성의 물리 복사로 해결하고 성공한 빌드를 사용했다.
- 브라우저 캡처는 데스크톱 공통 웹 범위다. 새 Codex/Claude 업무 실행·OS별 자동 열기·모바일·인쇄 쪽수·사용자 작업시간 측정은 이 검사의 범위가 아니다. 기존 심사위원 ZIP을 자동 교체하거나 새 릴리스를 게시하지 않았다.

# AA 동일 자료 실제 비교와 권장 범위

2026-10-16. [동결 계약](execution-quality-AA-method-20261016.md)에 따라 Codex·Claude CLI의6개 모델/추론 설정을 비교했다. **실제 부모 입력11개를 실행하고 독립 검토했다.** Codex 런타임의 파일시스템 정책 경고로 후속을 중단해 식기세척기 Sol low와 전자레인지 추가 확인2개는 실행하지 않았다. 원래14개 예약 분모를 보존하며, 12개 선별/14개 전체 통과나 최종 권장 확정으로 표현하지 않는다. 기본 실행 설정은 변경하지 않았다.

## 같은 자료에서 관측한 결과

시간은 CLI 시작부터 실제 native 프로세스 종료까지다. 준비·화면 렌더·사람 작업시간이나 순수 추론 시간으로 바꾸지 않는다. 점수는 출처·맥락·기획·전달 등을 대조한 내부 기준이며 공식 대회 배점이 아니다. 점수85 이상이어도 material P1/P2 또는 필수 실행·전체자료 조건에 실패하면 선별 통과가 아니다.

요청 모델 ID는 `gpt-6.1-sol`, `gpt-6-astra`, `claude-opus-5-5`, `claude-sonnet-5-5`다. 요청 인자·native 요청 context와 backend가 실제 보고한 모델/effort를 구분한다. 미보고 값은 `null`이며 모델 이름만으로 모든 계정의 이용 가능성을 보장하지 않는다.

현재 확인된 **조건부 후보는 Codex Astra low**다. 두 선별 과제에서 전체 자료와 실질 품질·현재 전달을 함께 확인했다. 그러나 마지막 Sol low 과제와 후보 전자레인지 추가 확인이 중단돼 최종 전체 업무 권장은 확정하지 않는다. Claude Opus medium의96/96이라는 내용 결과도 인정하되, 원본 metadata 전량 조건과 다른 사실로 남긴다. 과거 GUI 권장은 해당 버전의 참고 기록이며 이번 CLI 실험과 합산하지 않는다.

## 조사 폭과 품질을 함께 확인한 방법

격리 설치에 같은 원문219개·9모델을 복사했으나, 이번 실제 선별에 사용한 고유 범위는 냉장고56+식기세척기81=137개·6모델이다. 후기61·제품자료76이며 고유 고객 수나 시장 대표성이 아니다. 전자레인지82개는 예약 자료이며 이번 단계 실제 실행으로 세지 않는다. 새 온라인 조사의 속도·성공률도 이 수치에서 추정하지 않는다.

파일에 전체 원문이 있다는 사실과 부모가 실제 Tool 반환으로 읽었다는 사실을 분리했다. Sonnet DW의 helper는 일부 사실을 `quote[:1800]`으로 잘랐고8개 긴 자료가 축소됐다. 평가자가 원본을 줄인 것이 아니며 이 실행은 전체 폭 조건을 통과시키지 않았다. metadata 감사에서는 source_id 객체형식, 고유 모델/위치로 결합되는 동일 필드, 인용용10필드, 실제 값 누락을 구분한다. 예를 들어 CSM DW의 초기34개 식별은 고유키 결합으로81개 전량이 확인됐으므로47개 자료 누락으로 쓰지 않는다. 반대로 실제 SHA 값 부재는 형식 차이만으로 통과시키지 않는다.

독립 검토에서는 현재 저장본의 각 주장·인용 원문·후속 조건·검증계획과 completion/최종 답변을 대조했다. 후기의 긍정·자가대처·과거 제품·정상화·조건부 설명을 불편으로 바꾸지 않는지도 확인했다. 타당한 조건부 기획이나 미래 효과시험 자체를 실패로 세지 않았다. 남은 material 결과는 세 사례다.

- Opus low FR: 방문 전 영상 미확인과 방문 중 영상 제시 뒤 설명을 혼동한 저장 요약.
- Opus low DW: 관측되지 않은 ‘열풍60분 직후’와 안내 부재를 기획 전제로 확정한 저장 결과.
- Sonnet FR: 실제 파일명 대신 생략부호가 들어간 경로를 최종 답변에 전달. 정상 저장·자동 열기 요청과 수동 접근 실패를 구분했다.

현재 저장·export·웹·보고서의 버전 결속은11개 실제 실행에서 확인했다. 이것이11개 의미 품질/실험 조건 통과를 뜻하지 않는다. 현재 completion의 실제 전달도 단순 문자열 일치만으로 판정하지 않고, 전체 포함·재서술·실제로 접근 가능한 경로를 구분했다. 브라우저 육안 검수는 하지 않았다.

## 정책 경고와 미실행 범위

DW CSM native는912.047초 뒤 exit0로 종료했고 결과도 저장·전달됐다. 종료 후 수집한 stderr에는 Windows MXC의 실제 경고 `resource=filesystem backend=windows_mxc reason=policy_denied path=unknown`이 있었다. 공개 Tool 반환에서 구체 거절 명령이나 경로는 식별되지 않았다. 파일 본문의 인용이나 단순 파서 오탐으로 지우지 않았으며, 이를 자동 승인 검토의 특정 명령 거절이라고 바꾸지도 않는다.

수집기의 operator exit1과 `policy_or_permission_rejection`을 유지하고 제공사 중단 기준을 적용했다. 새 모델/GUI/권한 완화·재발송으로 우회하지 않았다. 미실행은 `AA_DW_CSL`, `AA_MW_SELECTED_CODEX`, `AA_MW_SELECTED_CLAUDE`의3개 예약이다. 실제 입력11, 자동 native 재발송0이다. 허용된 기존 산출물의 읽기 검토만 마감했다.

## 사용량과 발표에 쓸 범위

[행별 JSON](model-effort-AA-20261016.json)과 [그래프용 CSV](model-effort-AA-20261016.csv)에 정확한 초·요청/관측 설정·원문 폭·내부 점수·중단을 구분해 남긴다. 원본 로그와 개인 경로는 제품에 넣지 않는다. 부모와 실제 확인된 자식 사용량은 별도이며 중복 범위가 미확인인 값을 더하지 않는다. Claude terminal usage/modelUsage, Codex 입력 안의 cache와 출력 안의 reasoning도 중복 합산하지 않는다. 표시 가격은 실제 청구액이 아니며 사람 대비 절감률을 계산하지 않는다.

발표에는 **“같은 자료에서도 실행 설정에 따라 시간이 달라져, 자료 폭·내용·전달을 함께 검토했다”**고 제시할 수 있다. Codex 냉장고3설정의7분00초·11분32초·12분18초는 같은 질문·전체56개 원문의 실제 관측이다. 각1회이므로 보편 순위나 인과적 절감률로 쓰지 않는다. 조사 축소·중대 오류·정책 경고 사례를 속도 우승 설정으로 고르지 않는다.

검토 역할의 실제 기여는 COM FR의 시간순서2문구 수정과 COM DW의 원문 조건6묶음 보완으로 보여준다. child의 실제 원문 범위·partial handback을 유지하고 수정되지 않은 기획 전체를 새 성과로 포장하지 않는다. 역할 유무 대조 실험이나 항상 빠르다는 근거는 아니다. [별도 Token Lens](../../presentation-tools/token-widget/README.md)는 실제 동일 실행의 사용량을 재생할 수 있으며, REPLAY 표시를 유지한다. 촬영은 하지 않았다.

원래 전달 계약은 통과7/실패5, native succeeded11/timeout1이다. 이 숫자는 일반 성공률이나 상품성/효과 점수가 아니다. 7축 의미 점수는 목적·제약/모델 범위/불편 원문/기존 기능/제안/미확인·출처/완료 판단의 제한된 초안 평가다. 실제 효과·실물·대표성을 인증하지 않는다.

일반 AI 두 결과의 `original_statement_supported=false`는 원문에 직접 없는 제안을 정직하게 표시했다. 원래 코드가 이를 거절한 실패는 그대로 남긴다. 수정 계약에서는 `page_linked_example` 관측 pain에만 true를 요구하고 `conditional_draft` 제안에는 false·실제 전제 근거·가정·한계를 유지할 수 있다. unsupported/이전 제품/해소 완료/기존 기능 중복/치수 부족은 계속 차단한다. 기존 artifact와 false 값 그대로 별도 재검사에서 두 결과가 finalizable임을 확인했으며, 새 native 성공으로 계산하지 않는다.

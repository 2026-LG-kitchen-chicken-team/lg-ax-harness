# AI 직접 입력50개 회귀 결과

2026-10-11. 사용자 요청에 따라 [공개 샘플50개](../evaluation/regression50.md)를 실제 Codex에 입력하고 저장 결과·원문·독립 AI 검토를 대조했다. [비식별 개별 결과·실측](regression50-20261011.json)에 질문ID별 판정과 근거를 기록했다. 공식 심사문항·미사용 평가셋이 아니다.

| 항목 | 실제 관측 |
|---|---|
| 동결 대상 | product-planning-v6.0, 실제 저장 v4 근거, Codex0.162.0 |
| 실제 입력 / 대화 | 50 CLI 입력 / 40 native 대화 |
| 실제 모델 / 설정 | gpt-6.1-sol / ultra |
| 실행·최종 전달/저장 | 50/50 |
| terminal 결과 | completed18, held27, needs_input5 |
| 독립 의미 검토 | 50/50, 정의한7축 판정 통과50, 중대 오류0 |
| 전달까지 입력별 시간 | 중앙194.56초, p95 285.15초, 최대328.42초 |
| 저장 후보 수정 | 7입력에서 복수 후보, 그중5입력의 초기 거절 후보 보존 |

**50개 업무를 모두 해결했다는 뜻이 아니다.** completed18개도 근거가 제한된 조건부 기획·검증 계획의 완료다.27개는 부족한 근거·제약 때문에 보류했고5개는 추가 정보가 필요했다. 보류/질문은 판정 기준에 맞는지 개별 검토했으며 자동 통과로 처리하지 않았다.

독립 evaluator는 실제 원문과 정확 모델/문서 버전·출처 의미·불편→기존 기능→기획·제외 조건·미확인·최종/저장 일치·실행/검증 계획을 읽었다. 자체 평점·accepted·source_id 형식 검사는 의미 판정을 대신하지 않았다. 일부 중복 검토는 원본 지문과 점수가 같은지 대조하고 완료된 최신 독립 배치를 선택했다. 원본·초기 거절·검색 명령 오류는 비공개 이력으로 보존한다.

## 사용량

같은 native 대화의 누적 마지막 관측값을 한 번만 합산했다. 후속 요청마다 누적값을 다시 더하지 않는다.

| 관측 항목 | 토큰 |
|---|---:|
| 입력 전체 | 11,431,393 |
| 그중 cached 입력 | 9,968,128 |
| non-cached 입력 | 1,463,265 |
| 출력 전체 | 344,957 |
| 그중 reasoning 출력 | 99,705 |

cached는 입력의 일부, reasoning은 출력의 일부이므로 다시 더하지 않는다. 이 관측에는 평가용 전달/저장 프로토콜과 실패 후보 수정도 들어 있다.50 CLI 입력은 backend 모델 요청50회를 뜻하지 않는다. 전체 backend 호출 수·청구 비용·개발 evaluator 사용량·사람 업무시간은 unknown이며0으로 해석하지 않는다. 동등 baseline·반복 비교가 없어 이 수치로 토큰 절감률이나 사람 공수 효과를 입증하지 않는다.

## 재현 감사와 한계

`evals/runner/regression_audit.py`로 동결 입력·원래 prompt/native/stderr 지문·각 입력 원본과 집계·최종 메시지·export·후속 연결·독립 리뷰의 raw 결과 지문을 대조했다. Windows CRLF 기록과 동결 LF 텍스트의 표현 차이만 비교 때 정규화했고 원본 바이트·SHA·runner·receipt는 변경하지 않았다. 기존 `regression_report.py`의 표현 비교 실패와 최초 중복 리뷰 집계 실패를 보존했다. 감사 명령은 모델을 호출하지 않는다.

검증은 공개된 정상5개와 경계·후속·근거/제약/안전/효과 질문45개, 등록5모델의 저장 근거·단일 Agent·필요 Skill 범위다. 외부 웹 조사·자동 서브에이전트·실제 Tool 장애·Claude·임의 새 모델·일반 시장 수요·물리 안전·효과 실측·새 환경 사용자 경험의 통과율이 아니다. 질문에 판단 기준이 드러난 사례가 많아 예고 없는 심사 입력에 대한 일반화 근거로 사용하지 않는다.

후속 제품군 일반명·축약명·범위 유지10입력은 **v6.1 별도 동결/별도 실행**이다.50개를 v6.1에서 다시 실행했다고 합산하지 않는다. 일반 용어 입력 기능과 등록 모델 자동 확장·최신 자료 자동 조사는 구분한다. [웹 자료 정책의 확인/미확인/제안](web-data-analysis-20261011.md)을 함께 참고한다.

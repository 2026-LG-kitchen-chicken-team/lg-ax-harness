# 요청 기반 조사·등록 전환 — 2026-10-11

사용자 승인: 등록 사례 중심에 묶이지 않고 실제 질문의 제품/불편을 native AI가 판단해 조사·기획하도록 네 가지 후속 작업을 가능한 범위에서 진행한다. 자체 모델 API 실행기는 추가하지 않는다. 기존 LG 작업물은 재사용하지 않았다.

## 구현

- product-planning-v7.0, 기본 business-empty-v1(0모델/0출처). 과거 v4 자료는 평가 재현용으로만 남긴다.
- product_family는 공개 식별자이고 정확 모델/문서 scope는 계속 검사한다. 코드가 질문 키워드로 답안/제품을 고르지 않는다.
- 공개 HTTPS 조사, 실제 snapshot 발췌와 제조사 identity_review에 연결한 new_models 등록. 공식성/의미는 선언만으로 인증하지 않는다. 사설주소/DNS 재해석/잘못된 TLS·변조·버전 덮어쓰기 방지.
- open_request 원문과 조건 불변, 조사 사건/CAS/version 기록, resolve_request_bundle로 같은 요청의 turn 생성. 기존 turn 자료/수정상한을 재설정하지 않는다. 조사 보류도 turn 없이 export한다.
- Claude 검토에서 확인한 duplicates_existing 미확인 null, 원문 support_quote와 factual_summary/AI 해석의 구분을 Agent/Skill/저장 안내에 반영했다.

## 실제 검증

통합 제품 unit169개 exit0(최초 UTF8 테스트 오류1건과 과거 family 허용목록 기대 실패1건은 수정 이력 보존). 신규 연구 요청7개, 신규 자료/HTTP15개 포함. 이는 일반 코드 검사이며 실제 AI 품질 인증이 아니다. native 새 입력 실행·독립 검토·최종 receipt는 진행 후 아래 추가한다.

## 외부 의존성

원격 main만 존재하고 open PR은0개, web/는 착수 문서만 있다. 팀 웹의 실제 질문→실행기→저장/화면 코드는 미수신이므로 코드 검토/연결은 미완료다.

Gmail 최신 팀 회신3건을 다시 확인했다. 길웅 v0.3.0 결과는 기존 접수본이며 최신 제품 검증이 아니다. 로컬 유료 Claude 환경이 없어 최신 native 검증은 미실행이다. 진하의 사람 측정은 1차 중단/2차 미완료/3차 미시작, AI 도움 답안은 사람 직접 수행 비교로 사용하지 않는다. 길웅도 사람 측정은 별도 진행 예정으로 회신했다. 전체 원본 usage/완료된 사람 공수 없이 절감률을 만들지 않는다. 외부 발송은 이번 작업에 포함하지 않았다.

## 제한

Theme A 상품기획/근거/기획 검토 범위를 유지하며 모든 분야 업무를 자동 지원한다고 주장하지 않는다. 자료 품질·정확한 공식성·native 검색/권한은 실제 환경에 의존한다. 요청 장부의 연구 usage는 미측정이고 native 전체 세션 관측과 구별한다. socket timeout8초는 DNS resolver의 전체 종료시간을 보장하지 않는다. 전체 실행 제한은 평가 runner에서 적용한다.

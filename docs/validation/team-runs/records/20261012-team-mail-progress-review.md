## 최길웅 메일 업무 본문

개인 수신 주소와 헤더를 제외하고 본문을 인용했다. 아래 실행 명령은 보낸 사람이 설명한 사용법이며 이번 기록 작업에서 실행하지 않았다.

> 이량, 대겸, 진하에게. 길웅이야.
>
> CLI 작업 중에 나오는 시각자료를 터미널 대신 브라우저에서 보여주는 웹 화면 시제품을 만들어서 폴더째 보내. 각자 PC에서 바로
> 열어볼 수 있어.
> 디자인은 Streamlit 고객 리뷰 분석 시연 영상(KakaoTalk_20261009_191820838.mp4)을 따랐고, 화면
> 데이터는 내 Claude Code B502S33 세션(2인 가구 냉동 정리, turn 5개)의 실제 저장 결과야.
>
> 1. 여는 법
> - 첨부한 lgax-visual-viewer.zip을 풀고 report-B502S33.html을 더블클릭하면 열려. 설치나 서버는 필요
> 없어.
> - 자기 export로 만들려면 그 폴더에서 아래처럼 실행하면 돼. Python 3.10 이상, 표준 라이브러리만 써.
> python build_view.py --export <export 파일> --insights <insights 파일> --focus
> dashboard --open
> - B502S33 예시를 다시 만들려면 작업시간 측정 회신에 첨부한
> export(session-d8968adc...-fcd057f2....json)와 폴더 안의 insights-B502S33.json을
> 넣으면 돼.
> - 자세한 사용법과 화면 블록 형식은 README.md에 있어.
>
> 2. 화면 구성
> 요청·개요, 근거 대시보드, 후기 선별, 기능 대조, 제안, 진행 기록, 근거 원문, 내보내기 8개야. 왼쪽 단계 메뉴, 지표 카드,
> 도넛·막대·추이 차트, 아래 단계 자막을 넣었어.
>
> 3. 알아둘 점
> - web/ 범위는 대겸이 PM이라 기술이나 구조를 정하려는 게 아니고 참고용으로 보내는 거야. 나는 레포 읽기 권한만 있고 fork도
> 막혀 있어서 레포에는 올리지 않았어.
> - 실제 결과가 들어 있어서 레포 규칙대로 Git 대신 메일 첨부로 보내.
> - 화면은 저장된 export만 읽고 모델이나 업무를 다시 실행하지 않아. 아직 브라우저에서 export 파일을 바로 고르는 기능은
> 없어서 build_view.py로 한 번 변환해야 해.
> - 숫자는 등록된 근거 ID 목록으로 세고, 관측 건수를 발생률로 표시하지 않아. "냉동실 작음 5건 / 넉넉 5건" 같은 의견 묶음은
> 결과 문장과 검토 기록을 보고 Claude가 나눈 해석이야.
> - Gmail이 .js 첨부를 막아서 view-data.js는 빼고 보냈어. build_view.py를 실행하면 다시 만들어져.
>
> 첨부: lgax-visual-viewer.zip (68KB)
> SHA-256: 4cc5b2f2de64fd05bbcfa6053552664c65731f4aba13abc7dc9d606196ac7771
>
> 길웅

첨부 메타데이터의 실제 표시 크기는 **67,987바이트**다. 본문 SHA-256은 발신자가 선언한 값이며 이번 작업에서 다운로드 바이트와 독립 대조하지 않았다. 읽기 권한·fork 제한 설명은 발신 당시 팀원 보고로 보존하며 현재 권한을 판정하거나 변경하는 근거로 사용하지 않는다.

## 발표·시연에 반영할 범위

- 저장 결과 화면에는 재생 여부와 원래 제품·자료·실행 버전, 보류/검토 상태를 표시한다.
- 차트의 의견 묶음은 AI 해석이고 근거 ID 건수는 관측 집계다. 시장 발생률·중복 제거 완료·의미 인증으로 바꾸지 않는다.
- 새 자동 표시 훅과 웹 연결은 촬영할 제품 버전·환경에서 인수한 뒤 설명한다. 설치·trust 동의·출력 전달·원문 링크·잘못된 입력·자료 부족을 포함한다.
- 사람 대비 측정·회신 대기는 제외한다. 실제 관측된 AI 시간·usage와 미측정 부분을 함께 표시한다.
- 담당은 [팀 소유 범위](../../../decisions/team-ownership-20261012.md)를 따른다. 이번 작업은 메일·원격 자료의 기록/분석이며 제품·웹 코드 변경, 새 native 실행, 메일 발송을 하지 않았다.

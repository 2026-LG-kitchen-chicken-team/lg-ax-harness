# 길웅의 시각자료 웹 뷰어 메일 검토

2026-10-11 접수, 10-11~12 KST 검토. 새 메일 `[LG AX] 시각자료 웹 뷰어 시제품 공유 (B502S33 예시)`의 본문과 Gmail ZIP 미리보기 파일 목록을 확인했다. **ZIP 원본 바이트·코드·실제 화면 실행은 미확인**이며 채택·웹 통합 완료 기록이 아니다. 원문 메일·개인 식별자는 Git 제외 위치에 보관한다.

## 확인한 사실과 팀원 설명

- 메일 첨부는 `lgax-visual-viewer.zip`, Gmail 표시67987bytes다. 메일이 선언한 SHA-256은 `4cc5b2f2de64fd05bbcfa6053552664c65731f4aba13abc7dc9d606196ac7771`이다. 실제 다운로드 SHA 대조값이 아니다.
- Gmail ZIP 미리보기에서 `lgax-visual-viewer/` 아래 `build_view.py`, `index.html`, `insights-B502S33.json`, `README.md`, `report-B502S33.html`의5개 파일명을 확인했다. 파일 내용과 HTML 렌더링을 읽은 것은 아니다.
- **팀원 설명:** B502S33의 기존 Claude 세션5turn 저장 결과를 브라우저 화면으로 보여준다. 요청/개요·근거 대시보드·후기 선별·기능 대조·제안·진행 기록·근거 원문·내보내기8단계, 지표 카드와 차트를 제공한다.
- **팀원 설명:** Python 표준 라이브러리 변환기이며 export와 insights로 HTML을 생성한다. 모델·업무 재실행이 없고 브라우저 내 파일 선택은 아직 없다. Gmail이 JS 첨부를 차단해 `view-data.js`를 제외했으며 변환기로 재생성한다. 따라서 더블클릭만으로 모든 데이터/기능이 동작하는지는 실제 실행 검사가 필요하다.
- **팀원 설명:** 후기 의견 묶음은 Claude의 해석이며 관측 건수를 발생률로 표시하지 않는다. 실제 차트에 그 범위·분모·출처가 표시되는지는 미검증이다.
- 웹 범위는 황대겸 PM의 소유이며 길웅은 참고용 시제품으로 전달했다. 읽기 권한/fork 제한은 팀원 보고이며 이번에 권한을 변경하거나 원본을 웹 구현에 가져오지 않았다.

## 현재 요구와의 관계 — 새 검토 판단

저장 결과를 별도 프로그램으로 표시한다는 방향은 사용자 결정과 맞는다. 메일 설명대로라면 시각화용 모델 호출을 추가하지 않아도 된다. 다만 현재 확인 수준은 설명과 파일 목록뿐이며 실제 추가 호출0·재현 성공을 독립 인증하지 않았다.

이것은 **업무 결과를 재생하는 화면 후보**다. 실제 native Agent·Skill·Tool의 호출·메시지·시각을 관측한 실시간 화면이라는 증거는 없다. 첨부 export의5turn에 invocations가 비어 있어 그 export만으로 실제 Tool 사건·서브에이전트 메시지를 복원할 수 없다. 업무8단계나 turn을 실제 Agent 수로 표시해서는 안 된다. 기존 별도 관찰기와 같은 기능으로 채택했다고 해석하지 않는다.

B502S33은 예시 데이터이며 최신 v0.6.0의 신규 요청/빈 catalog 지원 범위를 이 화면으로 검증한 것은 아니다. [같은 기존 세션 export·사용량의 검토](20261011-claude-followup-mail-review.md)와 최신 native8입력은 구분한다.

## 실제 코드/시연 인수 전에 필요한 검사 — 미실시

1. ZIP 바이트 지문·코드·의존성·네트워크/모델 호출 여부를 확인하고 새 폴더에서 현재 export→변환→브라우저 표시를 재현한다. JS 제외본의 정적 HTML과 재생성 결과가 각각 어떻게 동작하는지 구분한다.
2. 모든 화면에 저장 결과 재생, 자료/제품 버전·관측일·검토 상태를 표시한다. completed와 semantic unverified/acceptance_ready=false를 함께 보여주고 보류·정정 전후를 숨기지 않는다.
3. 후기 묶음의 AI 해석, 동일 작성자/동일 근거 중복, ID 목록 집계와 발생률을 구분한다. 차트 숫자→등록 근거/원문으로 연결되는지, 원문/요약/기획 해석을 나누는지 확인한다.
4. 일반 제품명·다른 제품·최신 schema·근거 없음·조사 보류와 invalid turn을 넣어 확인한다. 실제 사건이 없으면 진행 기록을 업무 기록 재생으로 표시하며 Agent/Skill/Tool 사건을 만들어 채우지 않는다.

원본 ZIP 확보 과정에서 Gmail 커넥터는 ZIP MIME을 읽기 지원하지 않았고 브라우저의 다운로드 대기/파일 링크 받기는 각각20초 timeout이었다. `chrome://downloads` 조회는 브라우저 URL 정책이 차단해 우회하지 않았다. **원본 ZIP 수신·코드 검토·실행은 not_run**으로 남긴다. 브라우저 차단을 뷰어 코드 오류로 판정하지 않는다. 제품/웹 파일 수정·새 모델 호출·메일 발송은 이번 검토에서0이다.

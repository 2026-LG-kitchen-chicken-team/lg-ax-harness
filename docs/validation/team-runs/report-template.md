# 실행 보고서 양식 — 실제 결과 아님

이 파일은 빈 양식이다. 관리자는 실제 Issue/메일과 근거를 받은 뒤 개인정보를 제거한 사본을 `records/<run-id>.md`에 작성한다. 작성 전의 양식·가정·미실행 값을 실제 결과로 집계하지 않는다. 모르는 필드는 `미확인/미측정`으로 남긴다.

## 사용량과 보존

- 입력 / 캐시 입력 / 출력 / reasoning 토큰(필드별 실측 또는 미측정):
- 단일 turn/세션 누적/누적 차이 구분·native ID / 실패·하위 호출 포함 여부:
- 현금/크레딧 / 전체 청구·사람 공수(관측 또는 미측정):
- 비공개 원본 파일 종류·SHA / 삭제/가린 부분 / 관측 근거의 확인 범위:
- 보고서 정정 이력(날짜·작성자·변경 이유; 이전 실패를 제거하지 않음):

원문 로그·DB·인증·개인 설정을 Git에 넣지 않는다. `accepted/supported`는 모델 자기보고이며 검토 증거를 대신하지 않는다. 출력이 없거나 검토하지 않았으면 없는 상태를 그대로 기록한다.

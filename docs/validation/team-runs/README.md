# 팀원 실행·검토 보고서

실행자가 [Issue 양식](https://github.com/2026-LG-kitchen-chicken-team/lg-ax-harness/issues/new?template=harness-test-result.md)으로 결과를 제출하면 관리자가 실제 질문/출력·관측 근거와 민감 정보 제거를 확인해 `records/<run-id>.md`에 정리한다. 팀원은 코드 푸시 권한이 없어도 Issue로 접수할 수 있다. [기록 계약](../../evaluation/team-test-records.md)을 따른다.

- [환경·질문별 접수/검토 목록](index.md)
- [실행 보고서 양식](report-template.md)
- [질문 범위·미사용 평가 원칙](../../evaluation/coverage-and-holdout.md)

2026-10-10 사용자는 팀원들이 테스트했다고 알렸다. 현재 개별 보고서·출력 근거는 이 폴더에 아직 접수되지 않았다. 빈 양식을 실제 실행 결과로 집계하지 않는다. 새 보고서가 들어오면 접수/내용 검토/환경 인수 범위를 따로 갱신한다.

`records/`에는 개인정보를 제거하고 검토한 요약만 관리한다. 원문 실행 로그·SQLite·인증·의존성 환경은 제외한다. 폴더와 index는 자동 수집/대시보드가 아니며 실제 결과를 접수한 관리자가 갱신한다.

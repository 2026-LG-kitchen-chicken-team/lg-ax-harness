# 환경·질문별 팀원 실행 목록

2026-10-10. 사용자의 팀원 실행 완료 진술은 있으며, 개별 실제 입력·출력·환경 근거가 이 목록에 아직 접수되지 않았다. 접수 보고서 0건은 실행 0회를 뜻하지 않는다. 아래 빈 표는 제출/검토 준비 상태이며 미검증 환경의 성공으로 채우지 않는다.

| 실행 보고서 / Issue | 실행기·CLI·모델·OS | source·자료 버전 | 질문·turn | 실행 / 업무 상태 | 내용·계약 검토 | 오류·수정·재시험 링크 | 초·usage 범위 |
|---|---|---|---|---|---|---|---|

같은 조건의 첫 시도와 재시험을 각각 남긴다. 동일 질문·자료·설정·출력 계약이 확인된 실행만 직접 비교하고, 문장/모델/자료/권한이 다르면 해당 차이를 표시한다. 미응답·시간초과·미실행·증거 부족을 삭제하거나 성공률의 분모에서 조용히 제외하지 않는다.

결과 검토 후에도 native 지원·품질·비용·사람 공수의 검증 범위를 각각 판단한다. [기록 계약](../../evaluation/team-test-records.md)과 [보고서 양식](report-template.md)을 따른다.

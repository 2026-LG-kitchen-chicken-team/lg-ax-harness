전자레인지 G10-02의 최초 저장은 필드와 한계 개수 위반으로2회 거절됐다. 같은 턴에서 수정2회 후 저장했으며 초기 후보·거절·소비 사용량을 보존했다. 외부 native 재실행은0회다. 독립 의미 검토의 pointer 읽기 오류2건도 보정 전 실패로 보존한다. native의 없는 runtime-data 검색과 UTF-16 읽기 오류는 원본에 남아 있으며 전체 native exit0과 구분한다.

## 실측과 한계

입력별 전달까지 시간은 중앙192.59초, p95/최대320.94초다. 평가용 최종 전달·저장 프로토콜을 포함하며 사람 작업시간이나 병렬 전체 소요시간이 아니다.

같은 대화의 마지막 누적값을8대화에서 한 번씩 합산했다. 입력2,925,546토큰(그중 cached2,651,136, non-cached274,410), 출력61,590토큰(그중 reasoning22,088)이다. 부분집합을 다시 더하지 않는다. 실패 후보 수정도 포함한다. 전체 backend 호출 수·청구·개발 검토 Agent 사용량·사람 시간은 unknown이다. cached 비율90.62%는 baseline 대비 절감률이 아니다.

독립 검토는 원문 발췌 의미·정확 모델/버전·전제·제약·불편/기존 기능/기획·미확인·실행/검증 계획·최종/native/raw/export/읽기 전용 SQLite 일치를 대조했다. accepted·자기평가·source_id 형식으로 의미 점수를 대신하지 않았다. 미확정 요청은 실제 요청만 저장하고 resolved turn을 만들어내지 않았음을 확인했다. 감사 `evals/runner/family_audit.py`는 동결 입력/runner/원본 지문과 후속 연결을 확인하며 추가 모델 호출 없이 exit0였다.

공개 질문에는 판단 기준 힌트가 있고 등록5모델·후기8발췌·사실26개에 한정됐다. 청소 불편·식기세척기 건조 불편·내부 치수는 여전히 부족하다. 웹 조사·임의 새 모델 등록·Tool 장애·Claude native·일반화·사람 효과·물리 안전을 검증한 결과가 아니다. G10-06의 completed도 실제 청소 불편이나 효과가 관측됐다는 뜻이 아니다. 식품 제거 뒤 잔여 시야 불편을 먼저 관측하고 없거나 기존 서비스와 중복이면 중단하는 조건부 가설이다. G10-02 접수 화면 역시 접수 과정의 불편과 기존 지원 기능 중복은 미검증이다. rubric 통과는 사업성 실증을 대신하지 않는다.

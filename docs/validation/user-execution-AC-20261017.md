## 사용자가 열어볼 실제 결과

새 표시 구조에 과거 실제 AI의 저장 결과를 연결한 단일 HTML 3개를 제공했다. 냉장고56·식기세척기81·전자레인지82, 합계219개 원문 객체와 저장 결과·refs·현재 turn/version/binding을 보존한다. 목업 자료나 새로 지어낸 답변이 아니며, 이 미리보기 파일을 만들기 위한 모델 호출은0이다. 현재 제품 UI로 다시 표시한 것이므로 과거 AI 출력의 업무 시각을 이번 새 실행으로 바꾸지 않는다.

HTML 안에 데이터가 포함돼 별도 JSON·서버·sidecar 없이 전달할 수 있다. 본문에는 기획 판단에 필요한 내용을 먼저 배치하고, 상세 원문·조사 자료·기술 진단은 선택해서 읽도록 유지한다. 웹의 보고서 보기는 같은 저장 결과를 iframe `srcDoc`으로 표시한다. `report.html`이 따로 없다는 사실만으로 연결 실패로 판단하지 않는다. 독립 보고서 파일은 명시적인 standalone 생성 경로다.

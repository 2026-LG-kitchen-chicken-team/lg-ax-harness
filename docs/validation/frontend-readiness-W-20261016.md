## 데이터·화면의 연결 구조

`실제 AI 업무 → save/export → 현재 web-SHA.json → 현재 turn/버전/SHA·저장 검토 대조 → view-data.js → 기획자 웹 → 같은 turn의 보고서 HTML`

- 기획자 웹은 불편·기존 기능·콘셉트·근거·이력을 탐색하는 화면이다. React의 표시 문구 정리와 별개로 보고서 입력 원본을 먼저 분리한다.
- 보고서는 현재 turn만 포함하고 선택 등록본문 전체·refs·검토/조사 이력·검증계획을 유지하며 sandbox iframe에서 연다. AI가 매번 HTML을 새로 작성하는 기본 경로가 아니다.
- 결과 데이터는2초 주기로 다시 읽는다. 관찰 화면은 실제 사건 live.js를1초, 결과 메타데이터를4초마다 읽는다. 이 주기는 화면 반영 시간 보장 또는 추가 모델 호출을 뜻하지 않는다.
- 실제 화면에서는 제목·제품군·현재 버전·인용 번호·전체본문·검증계획이 서로 맞는지, 후속 결과 반영 때 보고서가 올바르게 바뀌는지를 확인해야 한다.

## 브라우저 접근 제한

`cua.createBrowserTab`으로 기존 실제 결과의 로컬 HTML을 열려 했으나 Browser Use가 다음을 반환했다: **“Browser URL policy blocks this action … requested URL protocol is not allowed. Allowed protocols: http:, https:”**. 같은 결과를 workaround·indirect execution·alternate surface로 얻으려는 시도도 명시적으로 금지했다.

사용자가 우회를 승인했지만 도구의 접근 통제를 해제하는 승인은 아니다. HTTP 로컬 서버·다른 브라우저/네이티브 경로·헤드리스 렌더링으로 전환하지 않았다. 스크린샷/클릭0회이며 눈으로 본 것처럼 평가하지 않았다. 사용자가 직접 확인한 화면·허용된 캡처를 제공하면 실제 가독성 검토를 이어갈 수 있다. 현재는 코드/데이터·계약 검사와 계획 갱신을 완료했다.

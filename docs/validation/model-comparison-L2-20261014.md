## 선택과 시간 해석

Codex Astra low 고정자료3회는 3/3 조건부 인수, 6분 51초~10분 44초이며 중앙값은 7분 31초다. 다른 Codex 모델·effort를 이번219 corpus로 전부 재순위화한 실험은 아니다. 이전 J2 탐색과 K1 인수는 해당 소스 이력으로 남긴다.

Agent 거부 도입 후 비교 GUI는 새 대화와 비어 있는 업무 runtime을 사용하고 설치86개·corpus3파일·질문·부모 Agent 거부 정책을 결속했다. 앞선 Opus 중간과 역할 혼입 실행에는 그 정책이 없었다. 생성한 scratch 파일과 공유 실행 환경의 캐시까지 매번 초기화한 cold 실험은 아니다. 순서·캐시·산출 내용·수정 횟수의 영향이 섞여 있으며 통계적 동등성·순수 추론 시간의 인과적 차이를 인증하지 않는다. ## 검토 역할과 전체 사용량

별도 Opus high 역할 실행에서는 product-evidence-reviewer가 실제 반환했고 빠진 설명서 반례를 지적해 메인이 제안 범위를 수정했다. 선택 근거29개, Tool 상태completed/내용partial, 공개 호출→반환125.067초다. 이 실행은 순수 모델/effort 시간 비교에서 제외하며 전체 실행 장부에서는 보존한다. 단일 관측의 개선을 품질 향상률로 환산하지 않고 자식의 OS 권한·자체 지문 검증·backend 전체 usage를 인증하지 않는다.

모든 main trace 관측 usage는 JSON에 제공사별 원필드와 coverage를 보존했다. OpenAI cached input은input의 하위 집합이고 reasoning output은output의 하위 집합이므로 중복 합산하지 않는다. Claude의 생성/읽기 cache 필드도 원형대로 남긴다. 실패·수정·역할 혼입 실행을 장부에서 빼지 않는다. 전체 backend/자식/청구·개발 사용량은unknown이며 금액·통제된 토큰 절감률·사람 공수 절감률은 주장하지 않는다.

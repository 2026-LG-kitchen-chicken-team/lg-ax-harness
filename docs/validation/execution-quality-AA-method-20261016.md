입력 기록 형식 주의: Windows의 `prompt.txt` 보관본은 텍스트 쓰기로 LF가 CRLF로 바뀌므로 파일 raw SHA가 봉인 문자열과 다르다. 각 보관본에서 오직 CRLF→LF로 정규화하면 봉인 UTF-8 입력과 정확히 같다. 실행기는 보관 파일 raw bytes 대신 봉인 `prompt.encode('utf-8')`를 binary stdin으로 전송한다. 보관본 지문을 실제 전송 지문으로 오표기하지 않으며 원본 보관본은 수정하지 않는다. 냉장고 원본 LF SHA `a2710fd14558e259c6582172baddf91a7b7d515d8501e0a736a69bef2e219bd7`와 보관본 CRLF SHA `041e3e589d4ed03cc2447d39a5a1b58274366ae4286db36b91a4b30805ccdee2`를 구분한다.

계정의 실제 모델 목록·인증과 공식 모델 설정 문서를 확인한 후보들이다. 요청 인자와 native가 실제 보고한 모델/추론 수준을 구분하며 미보고 값은 `null`이다. 특정 모델이 모든 계정에 제공된다고 가정하지 않는다.

냉장고에서 CSL→CSM→CAL, COL→COM→CSN 순서로 실행하고 식기세척기는 제공사별 역순으로 진행한다. 제공사별 동시 실행은1개, 전체2개 이하다. 두 선별 과제씩 총12입력을 먼저 평가하고, 자격을 충족한 제공사별 설정1개만 전자레인지 추가 확인2입력에 사용한다. 최대14입력이며 거절·오류를 숨긴 재발송이나 모델 대체를 하지 않는다. 전자레인지 자료는 이전 평가에도 사용됐으므로 새로운 미사용 데이터 일반화 시험으로 표현하지 않는다.

## 선별 기준

두 선별 과제 모두 아래 필수 조건을 충족하고, 해결되지 않은 material P1/P2가 없으며 내부 점수85/100 이상이어야 최종 후보가 된다.

1. 해당 제품군 전체 원문과 메타데이터의 실제 부모 전달, 원본 불변, 축소·잘림 여부를 확인한다. 파일에 저장됐다는 사실과 실제 Tool 반환으로 읽혔다는 사실을 구분한다. 개행을 공백으로 표시한 정보 보존과 본문/필드 누락도 구분한다.
2. 정확 모델·문서·출처 귀속과 긍정 평가·조건·부정·시간 순서를 보존한다. 새 출처, 기능 부재, 고유 고객 수나 시장 대표성을 만들어내지 않는다.
3. 현재 검토된 저장 결과와 업무 종료·export·웹·보고서의 버전 결속을 확인한다. native exit0과 저장 성공만으로 최종 전달을 통과시키지 않는다.
4. 실패·중단·거절과 실제 재시도를 보존한다. 시험 중 제품 코드·Skill·설정·원문을 바꾸지 않는다.

내부 점수는 출처/모델/조건25, 긍정 맥락15, 기존 기능/남은 문제/중복 판단15, 조건부 기획/반증 가능한 시험20, 저장/종료/전달15, 가독성10이다. P2는 기획 전제·결정·시험·사용자 행동을 실질적으로 바꾸는 오류다. 표현 취향이나 향후 시험 전의 조건부 기획 자체를 실패로 세지 않는다. 독립 의미 검토자는 검토한 주장·연결 원문·미검토 범위를 남긴다.

## 시간·사용량 해석

1800초는 중단 안전상한이며 목표 시간이나 결과 품질 기준이 아니다. 실제 시작부터 native 최종 종료까지 외부 경과를 사용하고, 도구 시간 합계나 에이전트가 쓴 자체 시간과 분리한다. 시간에 맞추려고 원문 수를 줄이지 않는다.

입력·출력·캐시·추론 토큰은 제공사가 보고한 포함 관계를 유지한다. 누적 snapshot과 개별 응답, terminal usage와 modelUsage, 부모·자식 사이의 중복 범위가 미확인인 값을 더하지 않는다. 자식의 실제 부모 연결과 로그가 확인되면 별도로 표시한다. 개발 검토 사용량은 제품 실행 사용량과 분리한다. 명목 API 환산액은 실제 청구액이 아니며 사람 대비 절감률을 계산하지 않는다.

동일 과제의 품질 자격을 먼저 판정한 뒤 관측 시간과 사용량을 비교한다. 작은 과제 수·캐시·실행 순서·런타임 변동을 남기며 보편적인 모델 순위나 인과적 절감률을 주장하지 않는다. GUI의 과거 성공 기록과 이번 CLI 비교를 동일 회귀처럼 합산하지 않는다.

## 중단과 관찰 범위

인증·정책·권한·모델·사용한도 거절이면 해당 제공사를 중단하며 결제·보안 설정 변경이나 자동 대체를 하지 않는다. 원본 지문 변경 또는 로그 상한 위반은 평가 중단 사유다. 브라우저 자동 열기 요청·산출물 바이트 검사는 실제 화면 육안 검수와 구분한다. 이전 자동 승인 검토가 차단한 브라우저 접근을 다른 도구나 주소로 우회하지 않는다.

발표 위젯은 [Token Lens 사용법](../../presentation-tools/token-widget/README.md)을 따른다. 모델 호출 없이 선택한 실제 로그만 읽고 LIVE/REPLAY를 표시하며, 제품 ZIP에는 포함하지 않는다. 결과는 별도 AA 검증 기록으로 인수한다.

# S06 시연·제출 원본 준비

2026-10-10. 발표·영상의 구성과 근거를 연결하는 준비 작업이다. 실제 발표 파일·촬영 영상·시간 리허설·최종 제출은 아직 완료하지 않았다.

## 작성한 원본

- [시연 실행 순서](../../submission/demo-runbook.md): 새 출품 폴더 준비, 실제 모델 질문, 원문·Skill/Tool·검토·저장/export 확인, 보류와 후속 질문, 촬영·재생 표시 기준.
- [발표 구성](../../submission/demo-plan.json): 14쪽, 예정 570초. C01–C09 요구를 공개 가능한 레포 근거에 연결했다.
- [제출 준비 안내](../../submission/README.md): 준비 상태와 미완료 항목, 업무 소스와 사적 실행 자료의 경계.
- [구성 검사](../../scripts/check-submission-preparation.py): 쪽수·시간 합계·요구 연결·근거 경로를 검사한다. 발표 내용의 의미나 실제 촬영을 자동 합격시키는 도구는 아니다.

공식 요구, 팀 제안서와 컨설팅, 현재 사용자 선택을 구분했다. 발표는 공식 자료의 20쪽 이내·10분과 질의응답 5분에 맞춘 계획이다. 제안서의 과거 일정은 공식 마감의 확정 근거로 쓰지 않는다. 제출 직전 영상 규격·마감 시각·제출 경로·파일명·변경 공지를 다시 대조해야 한다.

정상 시연은 실제 B502S33 자료의 기획 입력을 사용한다. 과거 R01의 실제 실행은 316.70초이므로 140초의 예정 시연 구간에 생중계가 끝난다고 보장하지 않는다. 전체 실행을 촬영한 뒤 대기 구간을 편집하면 편집 여부와 실제 시간을 표시하고, 기록 재생도 재생이라고 표시한다. test_only 합성 오류 자료는 실제 고객·시장·시연 근거와 구분한다. 별도 관찰 화면은 후순위이며 이번 준비에 구현하지 않았다.

토큰 비교는 이전/개선 조건에서 관측 입력 42.58% 감소와 실행별 시간 합계 2.09% 증가를 함께 설명한다. 강한 일반 프롬프트가 더 적은 토큰·시간으로 같은 소표본 기준을 충족했으므로 baseline 대비 품질·비용 우위를 주장하지 않는다. 사람 공수·현금/크레딧·전체 backend 비용은 미측정이다.

## 실제 검사

잠금환경 Python 3.12.14에서 아래 명령을 실제 실행했다. 모두 exit 0이다.

| 명령 | 확인 결과 | 한계 |
|---|---|---|
| `python scripts/check-submission-preparation.py` | 14쪽·570초, C01–C09 연결, 근거 파일 확인, errors=[] | 계획·경로 검사이며 실제 발표/영상 완료가 아님 |
| `python evals/runner/check_package.py --output .harness/hardening-submission-rehearsal.json` | 업무 ZIP 70파일, manifest 지문, 새 추출 폴더의 `uv sync --locked`·공통 Skill doctor·ZIP만으로 Claude 재설치 성공 | 소스·일반 코드 재현; 신규 환경의 native AI 실행은 미실행 |
| `python evals/runner/check_portable.py --output .harness/hardening-portable-validation.json` | Claude/Gemini 각각 새 폴더 54파일·업무 Skill 6개·잠금환경·파일 지문·doctor 성공 | 두 CLI 미발견·인증 미관측·native 발견/업무/예외/usage 미검증 |

이 ZIP의 SHA-256은 `9ccd5ec972e245754a0c05c59f470857f8919f2772a0dfa1e705424bd1fe4961`이다. 과거 재현 출력은 덮어쓰지 않았고 새 검사 결과·receipt는 Git 제외 `.harness/`에 보존했다. 원문 로그·DB·인증·의존성 환경·개발 평가 실행기는 업무 ZIP에서 제외한다.

읽기 전용 요구 분석자가 원본 제출 안내와 팀 제안서를 대조하고 위 준비 파일을 독립 검토했다. 중요 결함 없음과 구성 검사 exit 0을 보고했다. 이 검토는 실제 발표·영상·운영진 인수를 대신하지 않는다.

다음 작업은 발표 파일 제작, 실제 실행 촬영과 10분 리허설, 사람 공수 측정, 지원 환경 native 인수, 최신 제출 안내 대조다. 청소 불편·내부 치수와 넓은 AI 평가도 현재 [작업 목록](../plans/development-harness.md)의 미완료 상태를 유지한다.

# 자료 전체 전달·시간·출품 검토자 검증

이번 변경은 요청 기반 상품기획과 기존 실행기의 공통 Skill/Tool 연결을 유지한다. HTML·프론트·영상은 변경하지 않았다. 원문·실행 로그·DB·설치 사본은 Git 제외 위치에 보존하며 공개 기록은 비개인 수치·지문·판정만 담는다. [결정](../decisions/evidence-throughput-20261012.md)을 따른다.

## 구현 범위

일괄 자료 등록, 선택 범위 전체 원문 전달 장부, source별 검토/제외, 600초 workflow·전달 예약, 취소/종료 후 등록 거절, Codex/Claude의 선택적 근거 검토자 설치, 불변 reviewer packet을 구현했다. 첫 조건부 후보의 근거/한계 명시와 저장 전 진단, 현재 저장 결과에 맞춘 최종 답변 지침을 보완했다. 특정 질문의 정답·기획안을 코드에 넣지 않았다. 기본 출품 catalog는 비어 있다.

`collected → registered → delivered → caller-reviewed/excluded`를 구분한다. 마지막은 호출자가 남긴 검토 기록이며 AI가 원문의 의미를 올바르게 판단했다는 인증이 아니다. 원문 파일 SHA와 전체 목록을 유지해 독립 대조할 수 있게 한다. 검토자의 실제 실행 여부·완료/partial·반영·미측정 usage도 별도다.

## 실제 자료와 충분성

- 세 제품군 정확 SKU 10개에서 실제 HTTP 원본을 확보했다. 최종 파서로 재생한 관측 후기 99건 중 **다른 모델 7건 제외, 92건 등록**이다. 냉장고 22/전자레인지 40/식기세척기 30건이다.
- 제품 식별 10건과 정확 사양 영역 10건을 추가해 **등록 자료 112건**이다. 일반 Tool의 10개 import 묶음은 모두 완료했고 계측 0.766초다. 새 AI 조사 전체 시간이나 의미 검토 시간으로 사용하지 않는다.
- catalog SHA는 `c9792d24415d746ab1873343651352957598f33133c042ad0a6725ab8fb13654`다. 데이터는 평가 폴더에만 주입했으며 제품 기본값에 넣지 않는다.
- 초기 잘못된 헤더 추출, 파서 재생 실패와 그 원본을 보존했다. 최신 20사실을 이전 152 source chunk와 합산하지 않는다. 수집 시점·원본 SHA·정확 SKU·필드 위치·모델별 제외를 유지한다.
- 공식 설명서·지원 페이지와 개인 사용기 등 **8개 추가 원문**을 읽고 보존했다. 적용 모델/버전·문맥·인용을 아직 정확히 등록하지 않은 맥락 자료이며 112건에 합산하지 않는다. 이미지/OCR·설명서 전체 기능 적용·개인 후기의 사실 인증도 미완료다.
- T876 묶음의 9후기 중 정확 MD10681860은 2건, 나머지 7건은 다른 제품이다. 2건으로 일반적인 불편을 확정하지 않는다. 다른 모델로 대체하거나 suffix를 삭제해 동일 모델로 처리하지 않는다.

공식 JS의 페이지 요청/정렬/별점 필터를 확인했다. MW20GDN 표시 총수 1,571건·DUE6BGL1 623건에 비해 현재 본문은 각각 초기 10건이다. robots 허용 공개 카운트 요청에서 3점 이하 MW20GDN 18·DUE6BGL1 6을 관측했지만 **이는 본문 확보 수나 불편 발생률이 아니다**. 일반 수집 UA에 후기 추가 경로가 금지돼 해당 POST는 미실행이며 AI 웹 도구 popup 열람 3개도 실패했다. 추가 후기 본문은 0건이다. 저평점·장기 사용·여러 판매처의 독립 원문 보강과 대표성 검증은 남아 있다. [관측 robots](https://www.lge.co.kr/robots.txt), [공식 페이지 요청 JS](https://www.lge.co.kr/lg5-common/js/review/review.min.js), [공식 후기 본문 JS](https://www.lge.co.kr/lg5-common/js/components/lge-review.min.js).

새 수집 helper는 실제 UA로 robots를 선행 확인한다. 공개 경로·정확 SKU·charset·리뷰별 모델 ID·사양 전용 DOM·raw SHA를 검증한다. UA 사칭이나 제한 우회는 하지 않는다. 과거 실제 관측은 이력으로 보존하며, 후속 policy 확인을 과거 HTTP에도 수행했다고 바꾸지 않는다.

## 예외 시험의 실제 범위

이전 고정 설치에서 미등록 모델 held/export, 명시적 정책을 넣은 실제 resume 취소·cancelled/export는 확인했다. 모호한 일반 요청은 180초 timeout, 외부 조사 재시도도 180초 timeout이었다. `.invalid` URL은 전송 전 unsupported_url로 거절됐으므로 DNS 장애 복구 통과가 아니다. 취소 최초 runner는 읽기 전용으로 실행한 시험 설정 오류였으며 수정 실행과 구분한다. native/backend 전체 중단 보증은 unknown이다. 이 시험들을 최신 버전 전체 회귀 통과로 합산하지 않는다.

## 최종 소스 확인

최신 검사·설치 지문·native 결과는 [동반 JSON](evidence-throughput-20261012.json)에 기록했다. 제품 **338개 전부 통과/skip0/exit0/45.316초**, 평가 **143개 전부 통과/exit0/10.134초**다. 앞선 제품 skip1은 uv/Python 경로를 지정하지 않은 실행이며 최종 검사에서 실제 Codex·Claude 잠금 의존성 설치도 확인했다. asset·설치16검사도 exit0다. 다른 실행의 검사 수를 합산하지 않는다.

최종 packet은 원 후보 바이트를 그대로 두고 pretty JSON으로 전달한다. UTF16 후보65,536byte가 UTF8 packet 상한을 넘는 실제 결함을 재현하고 파일·DB 쓰기 전에131,072byte 상한을 검사하도록 고쳤다. 수집기의 복수 DOM SKU/DOM·JSON-LD 충돌/후기li 경계 결함도 독립 검토로 수정했다. 기존20원본 재생에서10모델·99관측후기·92등록후기·112기록과 정확 모델/후기 문자열이 전후 동일했다. 재생은 새 HTTP 조사가 아니다.

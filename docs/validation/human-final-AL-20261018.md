## 수정·연결 결과

- 실제 Claude Opus5.5/high 사용성 협의71.516초: 초안 전체 폭, 상단 HTML 저장, 공통 경고 중복 축소를 반영했다. 실제 이전 AK 기획을 최종 renderer로 표시한 브라우저 확인에서 초안 폭1156px/표client1082px=scroll1082px였다. HTML 저장 버튼의 클릭 안내는 확인했고 실제 다운로드 파일 저장은 확인하지 못했다.
- 제품 저장이 허용한 정확한 원문 발췌를 뷰어도 받도록 정합화했다. 원문 전체·모델/문서/위치/해시/출처 필드는 보존한다. 새 문구·빈 인용·다른 metadata는 거부한다.
- Codex 기존 GUI 대화의 새 질문과 최신 task_started 이벤트를 연결하고, 중복 request를 제거했다. 실제 Read로 반환한 자기 runtime JSON의 업무ID도 인식한다. 표시된 부분 읽기·잘림·result 밖ID는 거부하며 원문/명령/파일명은 관찰 로그에 저장하지 않는다.
- 관측된 위임/시작 없는 child 종료 꼬리는 완료를 대기로 돌리지 않는다. 실제 연결된 child는 반환 뒤 메인 반영까지 기다린다. 대시보드와 결과 전달의 같은 기준을 검사했다.

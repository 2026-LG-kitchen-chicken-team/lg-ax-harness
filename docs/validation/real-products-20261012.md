# 실제 제품 두 건의 조사·기획·보고서 인수

사용자의 완료 기준은 실제 제품 조사 → 근거 분석·기획 → 검토 → 저장 → 원문 자료집과 보고서 전달이다. 합성 목업의 출력 검수로 하네스 완료를 판단했던 이전 선언을 정정한다. v0.8.0의 출력 기능 검수와 과거 실패 기록은 이력으로 보존한다.

## 실제 자료와 기획 결과

2026-10-12에 새로 관측·등록한 LG B502S33 냉장고와 MWJ25E 전자레인지를 각각 정확 모델 범위에서 조사했다. 기본 배포 catalog는 빈 상태이며, 실제 원질문을 `open_request`로 보존한 뒤 같은 요청의 연구 ID에서 수집·등록하고 `resolve_request_bundle`로 연결했다. 중간 실패·제외 자료·모델 연결 및 날짜 정정 기록을 삭제하지 않았다.

| 대상 | 실제 선택 자료 | 검토한 기획 초안 | 확정하지 않은 부분 |
|---|---|---|---|
| B502S33 | 제조사·연결 설명서 사실 9항목, 공개 고객 후기 5사례 | 냉동 보관 과업과 얼음 필요를 구분하는 선택 안내 | 안내의 필요성·기존 콘텐츠 중복·고객 효과, 내부 치수·실물 부품 대응 |
| MWJ25E | 제조사·설명서 사실 9항목, GS SHOP 후기 2사례 | 기기 및 중간·종료·재알림을 구분하는 선택형 소리 패턴 | 기존 설정과 중복, 정확 모델의 펌웨어 실현성, 고객 효과 |

B502S33의 전체/냉장/냉동 용량은 [LG 정확 모델 페이지](https://www.lge.co.kr/product/refrigerators/b502s33?modelId=MD09091859&pdpType=PURCHASE)의 표시 사양이다. 외형 치수를 내부 수납 치수로 전용하지 않는다. 냉동실 관련 개별 의견의 긍정·유보를 함께 보존하고, 연결 설명서에 이미 있는 아이스메이커 제거·이동과 선반 안내를 새 기능으로 제안하지 않았다. 11번가 수집 메모의 이전 대형 냉장고 주변 문맥은 보존 발췌에서 독립 검증할 수 없어 본문 판단의 근거에서 제외했다.

MWJ25E의 [LG 정확 모델 페이지](https://www.lge.co.kr/product/microwaves-and-ovens/mwj25e?modelId=MD09144829&pdpType=PURCHASE), [지원 문서](https://www.lge.co.kr/support/product-MWJ25E)와 [GS SHOP 상품 후기](https://www.gsshop.com/prd/prd.gs?prdid=1094090458)를 대조했다. 소리 혼동의 약한 의견 1사례와 별도의 한 달 사용 긍정 사례를 합치지 않았고, 검색 발췌의 날짜 오귀속을 정정했다. 설명서의 기존 중간·종료·재알림과 일반 FAQ의 모델별 제한을 유지한다. 선택형 소리안은 구현·평가 전 조건부 기획이다.

정부의 가구·근로시간 통계와 Samsung 정확 모델 사양을 별도 주변 근거로 보존했다. 대상 제품의 수요·불편 발생률·효과로 확대하지 않았다. 원문 자료집은 제품별 20/19 발췌 기록이며, 두 보고서에 공통으로 들어간 주변 근거 3항목을 제외한 고유 기록은 36개다. 문서·사실 항목 수를 독립 사용자 수로 바꾸지 않는다. 구매일·게시일·관측일·협찬 확인 여부를 구분했다.

## 실제 업무 실행과 최종 소스 확인

| 항목 | B502S33 | MWJ25E |
|---|---|---|
| 실제 Codex thread ID | `01a12dac-13e8-7042-bf9e-20ee2910918b` | `01a12dac-13e8-7940-8efd-6e6a018114da` |
| 업무 실행 결과 | exit0 /639.92초 | exit0 /753.38초 |
| Dataset SHA256 | `7e740d4c2f50b339770e0994c859efe0aaa8732c169554f009432e502014a190` | `681959a9afffeb4ad5b46fe851442cd2b287dfc04c668be403c480d19ece47a3` |
| 저장 결과 | completed 조건부 초안 /valid version1 /revision0 | completed 조건부 초안 /valid version1 /revision0 |
| 입력/캐시 입력/출력 토큰 | 1,143,561 /1,058,048 /22,436 | 1,776,398 /1,688,064 /26,162 |

로그인된 Codex CLI 0.162.1의 사용자 모델 설정을 상속했다. CLI 실행 로그가 구체 모델명을 독립적으로 내보내지 않아 모델명을 추정하지 않는다. 위 수치는 해당 업무 thread가 반환한 usage이며 전체 개발 비용·청구액·사람 대비 절감률이 아니다.

두 실제 AI 업무는 source manifest `b2cff4ca2be75cc1f47edab983f20eefd5a10f1a527c9691c2afdf9bace6fd52`에서 실행했고 원본 작업 폴더·DB·로그·결과를 동결했다. 이후 모델 연결 guard와 출력 코드를 수정한 최종 manifest `3d790f846d806f9c64aba25a7c8755770827d9c1f56e41d3cb64413beee36873`는 새 검수 설치 두 곳에서 **보존된 실제 입력을 재생**하여 확인했다. 원질문·선택 자료·Dataset 지문·업무 후보·평가 SHA가 원본과 일치한다. 이 재생은 새 인터넷 조사나 추가 AI 업무 2건이 아니다. 원본 두 작업 폴더의 전체 파일 해시가 재생 전후 동일했다.

최종 재생은 빈 catalog → 원질문 → 같은 연구 ID의 제한 설정·보존 snapshot 등록 → 자료 import → 요청 resolve → 원래 후보·평가 저장 → 실제 파일 제작을 실행했다. 같은 저장 버전의 보고서 복구·재사용과 잘못된 version2 전달 차단도 확인했다. 기계 검사의 `semantic_status=unverified`와 `acceptance_ready=false`를 의미 품질 인증으로 바꾸지 않는다. 독립 검토는 근거 귀속·조건부 판단·기존 기능 중복·원문/본문 일치의 한정된 범위에서 판단했다.

## 바꾼 하네스와 검증 범위

- 원래 요청에 연결된 연구 ID의 기본 수집 한도를 유지하면서, 6–30페이지 범위의 명시적 예산 조정·사유·이력을 저장한다. 실패·재시도도 같은 연구 기록에 남긴다.
- 주변 시장·경쟁 근거는 같은 연구의 실제 snapshot·URL·SHA·원문 부분문자열을 검증해 보고서에 연결한다. 대상 모델의 업무 사실이나 후기 조건을 우회해서 충족시키지 못한다.
- 제조사 설명서의 문서군·절 marker와 정확 모델 지원 경로를 대조한다. 후기 popup 연결은 정확 모델의 등록된 부모 페이지와 실제 product ID/path를 요구한다. tracking ID·다른 상품 경로·빠진 ID·충돌 query는 거부한다.
- 원문 자료집에 자료의 시점·구매일·협찬 미확인·원문/해석 구분을 보존한다. 차트 제목 인쇄 폭·출처 끝행·PDF widow를 수정했다. 컨셉 이미지는 AI 제작 제안 시각화로 표시하고 실물·측정 결과로 사용하지 않았다.

최종 로컬 제품239검사(1개 platform skip), 평가128, eval28, 개발22는 모두 exit0다. 검사 결과·입력 지문·실제 로그는 로컬 receipt에 남겼다. 처음 발견한 잘못된 설명서 모델 연결의 코드 실패와 독립 검토의 P2, 초기 페이지 검수의 P2 3건, 재생 입력에서 필수 사유 누락으로 거절된 시도도 보존했다. 최종 결과가 과거 실패·timeout·다른 모델의 미인수를 소급해 해결하지 않는다.

최종 Windows 페이지 검수는 B502S33 PDF14/Word21/Excel22쪽, MWJ25E PDF14/Word19/Excel19쪽, 총109쪽·30시트다. 원본12파일 SHA는 검수 전후 일치했고, 원문 셀 연결135개 및 로컬 파일/셀 연결213개에서 오류가 없었다. 초기 P2 3건과 마지막 B Word 운영 문장 분리 문제를 수정 후 다시 확인했다. 검수 범위에서 전달을 막는 레이아웃 결함은 남지 않았다.

제품별 XLSX 4개(제품·고객 후기·시장 원문 및 보고서 도표), DOCX·PDF를 제공한다. 정확한 파일 SHA·시트·페이지·토큰값은 [JSON 인수 기록](real-products-20261012.json)을 따른다. 독립 내용 검토와 Windows Word/Excel·PDF 페이지 검수 범위만 보고하며, 실물 구현·고객 효과 실증·전 제품군 및 다른 환경·Claude 새 AI 인수·영상/최종 접수 완료는 주장하지 않는다.

# 보고서 이미지 제외·가독성 개선

사용자는 컨셉·시연 이미지 생성 기능을 제외하고 굵은 글씨와 글꼴 위계로 보고서 가독성을 개선하도록 요청했다. 최종 배포 번호는 별도 최신 지시에 따라 **0.8.1**이며 main 반영·릴리즈 확인 후 이번 작업을 종료한다. 새 조사나 이후 자동 점검을 추가하지 않는다.

image block의 작성 지침·검증·삽입·파일 해시 캐시를 제거했다. 일반 데이터 도표는 실제 수치가 있는 경우 계속 지원한다. 본문과 요약의 제한된 강조 표시, 굵은 한글 제목·소제목, 문단 간격과 실제 인용의 별도 서식을 적용한다. 임의 HTML과 인용 원문의 별표는 문자로 보존한다. 원문 XLSX의 문자열·자료 버전·URL·E셀 주소를 바꾸지 않는다. PDF의 한글 기울임 글꼴은 일반 글꼴로 대체되며 Word의 실제 기울임과 같은 표현을 보증하지 않는다.

보존된 실제 B502S33·MWJ25E 원자료를 서식만 재출력한 v5에서는 10개 파일·16시트·105개 실제 인쇄 페이지를 원해상도로 검수했다. 본문·도표·출처의 잘림과 겹침, 반복 머리글만 남은 페이지, 출처 고아 줄, 한글 글자 누락을 발견하지 않았다. 원자료 69·146항목과 기존 셀 값·유형·URL·원문 셀 주소를 보존했고, A3 원문 인쇄의 실제 본문 글자는 9.12pt, 도표는 최소 8.52pt였다. 새 조사나 새 의미 검토의 성공으로 세지 않는다.

추가 실제 입력의 더 긴 전자레인지 후기에서는 Excel 인쇄 E20·E35·E36의 첫 줄과 셀 경계선이 겹치는 문제를 확인했다. 최종 v6는 한글 등 넓은 글자의 폭과 명시적 줄바꿈을 계산하고 행 높이·위아래 여유만 보완한다. 원문 분할과 주소는 유지한다. 세 셀의 높이는 각각 130→174pt, 160→222pt, 160→206pt로 바뀌었고 실제 새 인쇄에서 경계선과 글자 사이의 여유 및 잘림 해소를 확인했다.

v6의 세 보존 자료 재출력은 총 15파일·26시트다. 새 Excel 인쇄 111쪽 전체 연락판과 핵심·밀집 10쪽을 원해상도로 확인했다. Word/PDF는 본문·스타일·링크 XML 및 해독한 PDF drawing stream이 정확히 같아 이미 전페이지 원해상도로 검수한 63쪽의 검수를 재사용했다. 새 Word/PDF 페이지를 다시 전수 검수한 것으로 쓰지 않는다. 원자료 146·69·111항목의 모든 기존 셀 값·유형·URL·원문 주소를 유지했고 최소 인쇄 글자는 8.52pt였다. 최종 전달 사본 15파일의 SHA256은 인계 원본과 모두 일치한다.

선택형 뷰어는 최길웅의 PR #6 이력을 보존해 통합한다. 기본 설치는 훅을 등록하지 않으며 업무·모델을 호출하지 않는다. 원문 전체 지문이 맞는 출처 종류 메타데이터만 연결하고 누락·불일치는 미확인으로 표시한다. 하위 junction·reparse 경로는 설치와 자동 훅 모두에서 거절한다. 실제 명령 검사에서 발견한 uv 시작 경고 출력과 Windows 한글 Python 경로 전달 문제의 수정 후 결과를 최종 릴리즈 기록에 남긴다. PR #7은 별도 draft로 유지한다.

# 보고서 출처 표시와 연결 개선

본문 아래에 긴 자료명·원문 위치·원문 셀 정보를 반복하던 출처 표시를 `출처 [1], [2]`로 줄였다. 문서 끝 `출처 목록`에 자료 정보를 한 번씩 모으고, 본문 번호에서 해당 항목으로, 항목에서 웹 원문·정확한 자료집 파일/시트/셀로 이동하도록 연결했다. 자료명에 이미 포함된 원문 위치는 다시 반복하지 않는다. 상세 등록 정보·전체 원문은 원문 XLSX에 그대로 보존한다.

공통 Agent, 보고서 작성 Skill과 독자용 출력 계약에 같은 규칙을 반영했다. 작성자가 번호를 직접 입력하지 않으며 `source_ids`에서 렌더러가 문서 전체의 첫 인용 순서로 번호를 정한다. 같은 source_id는 번호 하나를 재사용하고, 같은 URL의 다른 사실·설명서 절·후기 발췌는 별도로 남긴다. 공개 보고 계획 스키마는 바꾸지 않았다.

DOCX의 번호·bookmark와 실제 외부 링크, PDF의 번호·끝항목 destination 및 정확 원문 셀 링크를 검사한다. 독립 검토에서 발견한 DOCX 번호 삭제/PDF 다른 출처로 오연결 P2를 실제 부정 조건으로 재현하고, 현재 코드에서 두 경우가 `ready=false / reporting_verification_failed`로 거절됨을 확인했다. 렌더링 profile 변경은 같은 저장 버전의 새 파일 생성으로 반영하며 기존 결과와 업무 후보·평가를 보존한다.

## 실제 파일 검수

기존 B502S33·MWJ25E의 검증된 실제 원문·업무 후보·평가·본문·그림을 사용해 표시만 재생성했다. 새로운 웹 조사나 제품 업무 AI 실행은 0건이며 이 결과를 새 수집 성과 또는 제품명 한 줄 자동화 인수로 세지 않는다. 원래 업무·검수 DB와 기존 출력은 그대로 보존했다. 원문 XLSX의 값·자료명·모델/위치 정보·URL·셀 주소는 이전과 일치한다. ZIP 시각 등 때문에 새 파일 byte SHA는 이전과 다를 수 있다.

| 항목 | B502S33 | MWJ25E |
|---|---:|---:|
| 고유 출처 항목 | 20 | 19 |
| 본문 번호 연결 | 136 | 131 |
| PDF 페이지 | 15 | 15 |
| Word 실제 페이지 | 18 | 18 |
| Excel 실제 인쇄 페이지 | 18 | 17 |
| XLSX 시트 | 15 | 15 |

최종 Windows Word/Excel·PDF 총101쪽·30시트를 실제 렌더해 contact 및 확대 이미지로 검수했다. 본문 번호267개·끝 목록39항목의 대응과 웹/원문 셀 연결을 확인했다. 원문 셀 링크135개와 로컬 파일/셀 링크213개에 오류가 없었다. 원본12파일 SHA는 검수 전후 일치했다. 차트3개·제안 이미지2개와 실제 자료/표 수치는 이전 그대로다.

중간 출력에서 발견한 MW PDF의 문단/출처 분리와 B Word의 표/출처 분리는 paragraph 및 마지막 표 행의 페이지 유지 설정으로 수정하고 실제 페이지에서 재확인했다. 최종 검수 범위에서 전달을 막는 레이아웃 결함은 남지 않았다. 이전 출력과 P2 증거를 보존했다.

제품242검사(1개 platform skip), 평가128검사는 실제 exit0다. 출처/파일/현재 입력에 연결된 receipt와 독립 검토를 확인했다. profile은 `numbered-sources-v3`, reporting SHA는 `054693bccc3da18e7ff07cebbac281de0426438e1fb22622184e8072c89f4f8f`, 공통 source manifest SHA는 `39db949c1fd91975a24ebe5284d3a3211c649ff84a147c8789525fa2c9e92f42`다. 이는 표시·연결·보존 입력·Windows 페이지 검수의 한정된 결과이며 조사 충분성·의미 자동 인증·새 제품명 한 줄 실행·실물/효과·다른 환경의 완료를 뜻하지 않는다.

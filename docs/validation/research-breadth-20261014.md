# 실제 조사 범위 확대 인수

2026-10-14 빈 기본 catalog에서 세 제품군을 새로 조사했고, 관측 사례에 따른 조건부 상품기획·저장·전체 등록본문·최종 전달을 확인했다. 조사 충분성·시장 대표성·독립 고객 수·실물 효과 인증과는 구분한다. [비교 사전 기준](../evaluation/research-breadth-model-protocol-20261014.md)을 따른다. 같은 자료의 모델 비교와 최종 권장 기록은 별도로 마감한다.

## 바뀐 실행 계약

새 웹 조사에는 공식 사양·관련 설명서·외부 후기·후속 페이지·사용 조건·반례의 목표와 실제 scan을 연결한다. 정확 URL을 계획한 경우 실제 URL도 대조한다. 새 발견·남은 목표/범위·접근 실패와 실제 종료 이유를 보존한 뒤 현재 결과를 완료한다. 소수 건수나 ID 형식만으로 충분성을 인증하는 기능은 아니다.

조사 시 필요에 맞게 페이지 예산을 조정하고, catalog 상한을 16MiB로 늘렸다. 일괄 처리의 batch 상한과 전체 조사량은 구분한다. 자료를 줄여 시간 목표를 맞추지 않는다. workflow_status는 제한된 미리보기를 제공하되 완료 gate와 보고 집계는 전체 조사 장부를 사용한다. 전체 stop 입력은 불변 파일·SHA로 결속한다. PDF 설명서의 원문 독해는 유지하고 기본 업무의 PDF/DOCX·이미지·HTML 생성은 제외한다. 웹팀 화면은 이번에 수정하지 않았다.

현재 코드 L2 manifest는 `9939e2472091eaf8f017e47eb1297a3b7e57beb48870c17307b9e6884db5edc5`이며 업무 원본55개·설치86개다. 냉장고 조사는 보고 집계 보완 전 L1(`c0aa132b…d541`)에서 실행했다. 원본을 L2 실행으로 바꾸지 않았다.

## 품질과 현재 전달

세 결과의 전체 등록본문56/82/81개와 원문 지문·정확 모델·문서·인용·조건·긍정·완화·반례를 독립 대조했다. 전자레인지82/82, 식기세척기81/81은 같은 URL의 보존 snapshot에서 연속 본문 일치도 확인했다. 현재 DB·assessment·web_result·종료 export·completion과 실제 최종 접두부 및 두 전달 링크가 일치했다. 정형 저장 완료를 모든 의미의 자동 인증으로 확대하지 않는다.

식기세척기 제외 후기의 “5 선택”을 조사장부 일부에서 “5등급”으로 확정한 국소 표현을 발견했다. 정확 모델·옵션·에너지효율등급은 미확인이므로 “5를 선택했고 열풍이 불필요하다고 서술했으나 정확 모델·옵션은 미확인”으로 해석해야 한다. 정확 모델 미확인 제외와 최종 두 기획에는 영향이 없어 조건부 인수는 유지했다. 원본13점과 오류 이력을 보존하고 제안 전체 실패나 새 성공 실행으로 바꾸지 않았다.

## 같은 자료의 비교 준비 인수

219개 등록 record 전부를 비교 corpus에 보존했다. 본문·본문 SHA·origin·모델/문서 범위는 원 catalog와 일치한다. data_version과 deterministic source ID, 해당 spec/identity 참조만 바꿨다. 전체 원 관측·미등록 자료까지 모델에 전달한 것으로 설명하지 않는다.

비교 seal SHA는 `790817cbd5673be3f873d6fd3a6dc5c97c3823dda59ac32e7ad1f9b08ff9f62a`다. corpus 세 파일·provenance·L2 manifest, 실제 설치 파일86개, 요청 제품군과 비0자료, 질문 지문에 결속했다. GUI의 과거 비교 catalog는 비공개 보존 이동했고 새 catalog만 활성화했다. 이전 source-L2 기록의 과거 corpus 메타데이터는 비교 seal을 대신하지 않는다.

현재 L2 사전 거절/예외보존7검사 exit0, receipt `dbd6daceebdb44909dc469492cdabb8e`의 입력4개·원로그가 실제 현재 바이트와 일치한다. 마지막 검사는 코드에 예외를 주입한 검사이며 실제 예약 후 native 실패 사례가 아니다. 첫 외부 절대경로 input 제출은 도구가 거절해 검사 미실행이었고, 같은 바이트의 프로젝트 내 seal 사본으로 수정해 실행했다. 이전 L1의3검사를 L2 통과로 합산하지 않았다.

## 검사와 범위

제품 검사419건 중418통과·1skip, exit0(62.124초)다. 최종 receipt `f6249b004a6a464cbbf68728fa8298f3`와 입력7개를 현재 파일 바이트로 대조했다. 앞선 잘못된 Python 환경의 의존성 실패·검사 미실행·이전418검사 기록도 남겼다. 새 설치/doctor5명령 exit0 및 stdout/stderr10개 지문을 보존했다. 제품 ZIP 후보108개에는 원문·DB·로그·인증·개발역할·평가 질문을 포함하지 않았다. ZIP에서 native 모델을 다시 실행한 것은 아니다.

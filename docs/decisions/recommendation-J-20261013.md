# 출처 보완·권장 조합·녹화 시연의 새 실행 단계

2026-10-13 사용자는 남은 하네스 보완과 권장 모델/추론 수준 선정, 현장 영상 대체를 승인했다. 이후 Sonnet/GPT-6.1 Sol에 후보를 한정하지 말고 Opus·Astra 등 더 상위 후보도 비교하도록 명시했다. HTML/프론트는 웹팀 소유로 유지한다.

구 단계 G/H/I 추가24·기존21·누적45는 마감 이력이며 초기화하지 않는다. 새 사용자 승인 단계는 별도 J 장부에서 최대32개의 실제 모델 입력으로 기록하고 누적 최대77을 보존한다. prepared/문서 확인/코드 검사와 실제 native 입력은 구분한다. 실패·접근 거절·수정·후속 입력도 새 장부에 포함하며 자동 재발송하지 않는다. 유한1800초는 안전 상한이고 업무/영상 성능 목표가 아니다. 자료 폭을 줄이지 않는다.

실행 전에 동일 문서의 정형 근거 연결, 사실/해석·조건·현재 긍정 분류, 실제 검증계획·시간 명칭, 실패 응답 보존을 일반 규칙/코드로 보완한다. 정확 URL/query·모델 식별 원문·scope·research·관측시간/SHA 없이 모델명을 삽입하거나 URLprefix로 자료를 승격하지 않는다. 이후 새 source J를 동결하고 이전 H/I 점수를 옮기지 않는다. 기본 catalog는empty다.

모델 탐색과 최종 권장은 분리한다. 계정에서 가능한 Codex Sol/Astra/Luna·Claude Sonnet/Opus/상위 후보를 확인하고, 실제 접근 가능한 명시 조합만 충분한 동일 자료로 시험한다. screen1회는 후보 탐색이며 권장이 아니다. 제공사별 finalist는 냉장고28/전자레인지48/식기세척기36 자료를 각2회 확인한다. 출처 의미·실제 전달·중대 오류·실패 분모와 품질 손실을 먼저 평가한 뒤 시간과 관측 usage를 비교한다. 가용하지 않은 모델·GUI를 다른 제공사/CLI로 임의 대체하지 않으며 전체backend청구·effort비등가를 보존한다.

현재 Claude Max/Sonnet5.5/중간 표시는 확인했지만 Computer Use 창 활성화는 실패했다. 사용자 추가 승인 뒤 창 재선택·표시 동작·세션 핸들 재초기화를 시도하며 실패를 보존한다. 물리 Esc/사용자 중단을 자동으로 재개하지 않는다. 인증·전역 보안/권한/구독은 변경하지 않는다.

현장 직접 실행 시연 대신 **실제 실행 녹화 영상을 발표자료에 삽입**한다. 본대회 발표+영상+전환 합계600초를 설계한다. 실제 업무 수행시간·연속 원본 영상·편집/배속 시간을 구분하고, 긴 대기/편집은 표시한다. 냉장고 중심, 전자레인지/식기세척기 확장, 평가항목과 토큰 가산점 근거를 같은 버전·실행에 연결한다. HTML 화면 인수·실제 촬영·편집·삽입 재생·리허설·접수 완료를 계획으로 대체하지 않는다.

root는 primary의 단일 작성자이며 데이터 연결 구현은 깨끗한 기존 managed worktree를 별도 branch로 재사용한다. 기존 dirty worktree/팀 파일/사용자 미추적4문서·원본·기존 release를 보존한다. 실제 검사·독립 리뷰·소스별 품질 판정 뒤 의미 있는 제품 변경만 새 시험판으로 게시한다. 원격 CI 결제 제한과 로컬 검사·실제 모델 품질은 구분한다.

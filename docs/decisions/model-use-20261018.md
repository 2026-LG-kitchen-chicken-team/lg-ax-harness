# 실제 비교 후 권장하는 실행 설정

2026-10-18. [AL 동일 자료 비교](../validation/human-final-AL-20261018.md)와 [행별 CSV](../validation/model-effort-AL-20261018.csv)를 현재 권장의 근거로 삼는다. 2026-10-17의 AA 권장 표는 당시 이력으로 보존한다.

| 실행기 | 시작 권장 | 비교한 다른 선택 | 판단 |
|---|---|---|---|
| Codex | GPT-6.1 Sol / medium | GPT-6 Astra / low | Sol은 냉장고292.906초·식기세척기461.328초에 대안 비교·선택·실제 초안·출처를 전달했다. Astra도390.718초·464.813초에 같은 완료 항목을 충족했다. 이번 과제에서는 Sol을 일상 시작값으로 둘 근거가 있으며 Astra는 대안으로 남긴다. |
| Claude Code | Opus5.5 / medium | Opus5.5 / high | 중간은899.374초·1122.485초, 높음은1075.985초·1151.448초였다. 각 결과의 근거와 실제 초안을 검토했고, 높음을 기본으로 올릴 만큼의 반복적인 품질 우위는 확인하지 못했다. 기존 중간 기본값을 유지한다. |

이것은 **현재 업무의 실용 권장**이다. 같은 코드·질문·등록 자료로 프로필/제품별1회 수행했고 선택적 검토자 사용·동시 실행·PC 부하가 달랐다. Codex의 process exit 시계와 Claude의 사람 질문→최종 main Stop 시계도 구분한다. 평균 속도·통계적 순위·항상 우수·절감률·다른 모델 열등을 주장하지 않는다. 사용자가 모델을 바꿀 수 있지만 이용 가능한 모델과 추론값은 실행기에 표시된 실제 선택을 기록한다. 자동 fallback으로 비교 대상을 바꾸지 않는다.

등록 자료56/81건을 그대로 제공했다. Claude medium 식기세척기의 실제 main Tool 문맥은80전문+1부분이었으며 backend81 전달과 구분한다. 이 비교는 새 온라인 수집시간이나 고객 대표성을 측정한 것이 아니다. 새 웹 조사는 사이트 접근성과 자료량에 따라 시간이 더 필요하다. 시간을 맞추려고 원문 폭을 줄이거나 조사1~4건으로 축소하지 않는다.

Codex GUI는 실행기 기본 설정을 상속하며 앱의 모델/추론값이 CLI 옵션과 같다고 가정하지 않는다. Claude GUI도 실제 Code 화면에서 선택을 확인한다. 새 Claude GUI 업무는 앱 제어 연결이 없어 수행하지 못했으며, CLI 성공이나 Desktop 열기로 대신 인증하지 않는다. 계정 인증·요금제와 실제 backend 청구는 별도이며 이 하네스는 추가 LLM API key를 요구하지 않는다.

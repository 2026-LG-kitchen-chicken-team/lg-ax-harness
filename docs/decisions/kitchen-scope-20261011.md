# 세 제품군 확장과 실행기 범위 변경

2026-10-11 사용자 결정. 이전 냉장고 우선/세 실행기 지원 목표를 이 결정으로 갱신한다. 과거 검사·실패·릴리스는 당시 범위의 기록으로 보존한다.

- 업무는 Theme A 상품기획이다. 냉장고·전자레인지·식기세척기에서 **실제 원문이 뒷받침하는 불편**을 발견하고 같은 모델의 기존 기능과 대조한다. 제안서의 수납·정리·청소 예시에 제한하지 않는다. 사용자에게 상세 불편을 대신 입력하게 하지 않는다.
- Codex가 현재 제출 기준 실행기다. Gemini 지원을 철회하며 활성 installer/profile/package에서 제거한다. 2026-10-10의 인증 거절(exit55)과 미인수 기록은 삭제하지 않는다. 기존 Gemini 설치 사본·전역 설정·계정은 변경하지 않는다.

- 웹팀은 현재 작업 중이라는 사용자 보고를 반영한다. 웹 PM 황대겸의 소유 범위를 유지한다. 레포에서 구현 원본을 받지 않은 상태를 팀이 개발하지 않는다는 뜻으로 쓰지 않는다. 메인은 결과 계약/근거/오류·지원 상태를 연결하며 프런트엔드를 독자 구현하지 않는다.

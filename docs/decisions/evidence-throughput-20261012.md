# 자료 폭을 유지하는 실행·검토 결정

사용자 지시: 리뷰와 자료조사를 극소수로 줄여 시간을 맞추지 않는다. 목표는 300초, 전체 상한은 600초다. HTML·프론트는 웹팀 소유이며 이번 변경에서 수정하지 않는다. 사람 대비 효과·Gemini 지원은 제외한다.

## 채택

- 기존 Codex/Claude Code 실행기를 유지한다. 자체 모델 API 실행기는 추가하지 않는다.
- 출품은 메인 상품기획 Agent 1개, 업무 Skill 6개, **선택적 독립 근거 검토자 1개**다. 개발 체계의 역할 6개/Skill 9개와 구분한다. 위험한 모델 귀속·기존 기능 중복·공식 원문/해석·조건/반례를 대조할 때만 검토자를 사용한다.
- 원문 등록은 모델이 긴 JSON을 반복 작성하는 대신 파일 기반 일괄 Tool로 처리한다. 원본 SHA·정확 모델·버전·순서·실패 배치를 보존하고, 일부 실패를 전체 성공으로 바꾸지 않는다.
- 자료를 모두 전달받았는지와 검토/제외 기록이 있는지를 일반 코드로 검사한다. 이는 의미 검증·대표성·전체 웹페이지 열람의 인증이 아니다. 임의의 최소 건수나 상한 건수를 충분성 판정으로 쓰지 않는다.
- 검토자에게는 원 후보의 불변 사본/SHA와 질문·현재 요청/turn·code/data/context/scope/버전을 묶은 packet을 준다. 반환 후 결속을 다시 확인하며 수정 후보는 별도 파일로 작성한다. `ready`는 저장 승인이나 의미 통과가 아니다.
- 새 workflow는 600초, 300초 중간 점검, 마지막 90초 전달 예약을 사용한다. 검토자 90초와 반영 30초를 확보하려면 최소 210초가 남아야 한다. 부모가 실제 native ID·상태·시계를 관리한다. 역할 `maxTurns`만으로 90초 중단이 강제되지는 않는다.
- 시간 단축은 반복 지침 읽기·거절된 동일 후보 재저장·긴 생성 명령·원문 직렬화/파일 제작부터 줄인다. 공식 사실을 바꾸거나 미확인을 확정으로 만들어 검사를 통과시키지 않는다. 조건부 기획은 첫 후보부터 실제 한계와 `conditional_draft` 근거를 명시한다.
- 자동 Skill 발견 후 메인이 문맥에 따라 필요한 Skill을 적용한다. 모든 사용자 입력에 명시적인 `/skill`을 요구하거나 모든 전문가를 항상 실행하지 않는다. 구조 정의·파일 설치·실제 발견·실제 위임·품질 이점은 각각 구분한다.

## 실제로 확인한 이점과 제한

Claude Desktop Code에서 읽기 전용 검토자가 약 40초에 완료했고, 부모가 모델 귀속·반례·불확실성을 수정했다. 한 번의 실행에서 확인한 품질 이점이며, 전체 업무는 후보 저장 검사에 실패했다. Codex의 비교 실행에서는 검토자가 90초 안에 완료하지 못해 중단했고 부모가 이어서 전달했다. 필수 다중 Agent 구성이나 속도/토큰 절감으로 일반화하지 않는다.

모델·추론 수준의 최종 권장과 실제 검사 수치는 [검증 기록](../validation/evidence-throughput-20261012.md)을 따른다. 서버 카운트·페이지 첫 목록·개인 후기·설명서의 성격을 구분하며 차단 경로/UA 사칭/인증 우회로 자료를 늘리지 않는다.

공식 네이티브 역할 기능의 근거: [Codex subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents), [Claude subagents](https://code.claude.com/docs/en/sub-agents), [Claude Desktop Code](https://code.claude.com/docs/en/desktop). 해당 기능 지원이 우리 설치의 권한·시간 강제나 모든 업무의 품질을 보증하는 것은 아니다. 서브에이전트 수에 대회 가산점이 있다는 공식 근거는 확인하지 못했다.

Claude는 **Desktop Code의 Opus 5.5 / 노력 높음**을 검증한 운영 조합으로 권장한다. 부모 단독 전자레인지2회·냉장고·식기세척기를 4/4 인수했다. 이는 CLI 인증/API 실행기 인수가 아니다. Sonnet 5.5 높은 추론은 전자레인지 한 실행의 유효한 대안 후보이고 다른 두 제품군의 동일 버전 검증은 이번에 수행하지 않았다.

처음 후보 선택에서 Opus high는523.899초·12/14, Sonnet high는678.643초·13/14로 모두 core0였고 더 짧은 Opus를 반복·제품군 확장 대상으로 정했다. 반복 시간 변동을 확인했으므로 ‘항상 가장 빠르다’는 권장은 아니다. 중간 추론의 두 GUI 사례는 각각 핵심 기획 전제/미수행 전량 읽기 완료 고지로 미충족이었지만 작은 표본의 결과를 제공사·모델 전체의 한계로 일반화하지 않는다. Fable은 이용 가능 화면만 확인했고 역할 혼입 재확인에 입력 상한을 사용해 실행 순위를 판단하지 않았다.

권장 범위는 등록 실제 원문의 조건부 상품기획과 현재 전달이다. 새 웹 조사는 접근·자료 충분성에 따라24~27분이 관측됐고 고정자료 시간과 섞지 않는다. 자료 폭을 줄여 시간을 맞추지 않는다.1800초는 안전상한이며 성능목표/SLA가 아니다. 사용자 선택에 따라 본대회 발표·시연10분은 검증한 실행 영상으로 구성한다. 편집 영상 길이를 전체 업무 처리시간으로 설명하지 않는다.

전체 숫자는 정형 sources.kind·본문 지문·현재 결과에서 코드로 집계한다. 일부 AI 서술의 후기/공식 건수 오류를 그대로 UI·발표 수치로 사용하지 않는다. 시점·모델·미확인·단발 관측·조건부 가설을 유지하고 효과·원인·대표성을 확정하지 않는다.

동일 모델/effort에서도 결과와 시간이 바뀌며 일부 국소 귀속·긍정 조건·시험계획 상세 보완이 남는다. 중요 상충·공식 문구 귀속은 선택 검토자에게 연결하고 항상 모든 역할을 호출하지 않는다. 비교용 Agent 거부는 격리 평가 프로젝트에만 적용했고 출품 원본이나 전역 설정에 강제하지 않는다. 실제 역할 이점은 단일 reviewer 사례로 입증한 범위다.

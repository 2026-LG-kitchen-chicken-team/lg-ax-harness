# 보고서 표현과 선택형 뷰어 통합

2026-10-12 사용자는 보고서의 컨셉·시연 이미지 생성 기능을 제외하고, 굵은 글씨와 글꼴 위계로 가독성을 개선하도록 요청했다. 작성 지침의 이미지 생성 경로, image block 계약·검증·삽입·캐시 경로를 제거한다. 기존 결과는 이력으로 보존한다. 실제 조사 수치를 그린 데이터 도표는 유지한다.

제목·소제목은 크기와 굵기로 구별하고 본문의 행간·문단 간격을 통일한다. summary와 본문 paragraph는 제한된 강조 표시를 해석한다. 임의 HTML은 문자로 남긴다. 실제 인용은 별도 quote 서식과 리터럴 표현을 유지하고, 원문 XLSX 및 출처 목록은 본문 강조 표시를 해석하지 않는다. 한국어 기울임 폰트가 없는 PDF 환경은 일반 글꼴로 대체되므로 Word의 실제 기울임과 같은 표현을 보증하지 않는다. 검수는 굵은 한글 글꼴, 제목 위계, 원문·번호·링크 보존과 실제 페이지 가독성을 확인한다.

최길웅이 원격에 올린 PR #6의 저장 결과 시각자료 뷰어를 선택 기능으로 통합한다. 기본 설치는 훅을 등록하지 않는다. 업무 질문과 모델 실행은 기존 native CLI에서 진행하며 뷰어는 export를 읽는다. 원저자 이력을 보존하고, 설치 후 하위 junction·reparse 경로와 원문 지문이 맞는 출처 종류 메타데이터를 검사한다. 전역 CLI 설정·인증·권한을 자동 변경하지 않는다.

PR #7의 localhost 관찰 프로그램은 별도 draft다. 실제 재검토에서 malformed 거절 후보의 null 출처 처리와 포트 변경 재설치의 관리 훅 중복을 확인했다. 두 뷰어의 자동 훅을 함께 기본 활성화하지 않는다. PR #7의 파일·테스트 검토를 새 native 업무와 브라우저 인수로 설명하지 않는다.

GitHub #8의 브랜드 미지정 대상은 국내 LG로 유지한다. 사용자가 명시한 모델·브랜드·시장을 원질문과 함께 보존하며 동일 범위의 후속 요청도 정책을 이어받는다. export는 원후보를 바꾸지 않는 출처 종류 메타데이터를 제공한다. Codex Windows sandbox 준비 오류에 대한 팀원의 node_repl 비활성화 시도는 별도 환경 확인이며, 전체 접근 모드의 성공으로 일반 sandbox 해결을 인증하지 않는다.

실제 새 조사 인수와 보존 자료의 서식 재출력, 일반 코드 검사, Word/PDF/Excel 검수를 구분해서 최종 검증 기록에 남긴다.

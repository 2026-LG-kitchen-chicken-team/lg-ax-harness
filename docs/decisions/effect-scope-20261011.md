# 사람 대비 절감효과 측정 제외

2026-10-11 사용자는 “사람 대비 절감 효과는 안해도 됨.”이라고 지시했다. 사람 직접 수행 기준선·팀원 측정·회신 재촉·AI와의 시간 절감률 계산을 현재 작업과 완료 조건에서 제외한다. 과거 측정 안내·미완료 회신은 이력으로 보존하며 새로운 요청을 보내지 않는다.

AI 실행시간·토큰·실패·답변 품질·근거 검증과 제품 개선안의 구현/검증 계획은 유지한다. 측정하지 않은 사람 대비 절감률·사업 효과를 제시하지 않는다. 이는 사용자 작업 범위 결정이며 운영진의 공식 평가 규정을 변경했다는 뜻은 아니다.

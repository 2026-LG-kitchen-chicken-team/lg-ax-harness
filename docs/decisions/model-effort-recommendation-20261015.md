2026-10-15 O 단계. 동일 최종 소스·같은 냉장고 질문·전체 등록 근거56개를 부모 단독으로 순차 실행했다. 설정별 한 번의 실제 결과를 검토한 실용 권장이며, 시험하지 않은 모델 구간 전체의 지원·성능 순위로 확대하지 않는다. [원본 인수 기록](../validation/skill-runtime-O-20261015.md)이 판정과 시간의 기준이다. 두 실행기의 세 제품군·후속과 Codex의 별도 온라인 조사까지 실제 업무12건의 핵심 요청·저장·전달 검토를 마쳤다.

Codex와 Claude는 실행자가 보유한 해당 제품 계정·권한으로 사용한다. 공통 Skill·도구를 각 실행기에 설치하며 자체 모델 API 프로그램이나 실행기 간 자동 전환을 추가하지 않는다. Codex CLI0.162.0, 실제 Claude 모델 ID `claude-opus-5-5`를 기록했다. Claude의 effort는 실제 UI 선택이며 backend effort 필드는 unknown이다. 모델 접근 가능성은 실행 계정에서 별도로 확인한다.

비교에서 국소 표현 의견과 핵심 기획 실패를 구분했다. 각 설정이 같은 기획 문구를 내도록 맞추지 않고, 실제 요청·원문 귀속·기존 기능 대조·조건/반례·검토된 저장 결과의 최종 전달을 확인했다. 효과를 측정하기 전의 타당한 검증 계획을 실물 실험 미완료라는 이유만으로 실패 처리하지 않았다.

Codex는 native 최종 답변 뒤 process exit, Claude는 실제 native `end_turn`까지의 시간이다. GUI 갱신 지연은 별도다. 회복 실행425.640초는 최초 CLI 인자 실패0.203초와 운영자 준비 간격까지 합친 전체 대기 시간이 아니다. 서로 다른 업무·자료량의 시간 차이를 모델 설정만의 효과로 귀속하지 않는다.

원문 범위를 줄이지 않았다. 평가용 등록 자료는 세 제품군219개이고 각 제품군 전체를 전달했다. 이 숫자는 고유 고객 수나 시장 대표성이 아니다. 신규 온라인 조사는 동일 자료 모델 비교와 나눠 판정한다. 연구 폭과 품질을 보존하고 실행 시간은 결과로 관측한다.

발표에서는 **“같은 근거와 질문에서 품질을 확인한 뒤 실행 시간으로 설정을 선정했다”**고 설명한다. 화면 제작은 웹팀의 공통 프론트가 담당하고 AI는 현재 정형 결과·근거·이력을 전달한다. 지침 선택 로딩·동일 지문 재반환 생략·일반 코드의 조회/저장/검사를 토큰 효율 기법으로 제시한다. 측정하지 않은 하네스 전후 절감률이나 실제 사람 대비 절감률은 사용하지 않는다.

선택 역할은 필요한 경우에만 사용한다. Claude 후속에서 근거 검토자1명의 실제 반환과 부모 수정 반영을 확인했다. Codex 온라인은 공식자료 조사자와 근거 검토자2명이 실제 반환됐고 검토자의3개 지적이 첫 저장 전에 반영됐다. 공식 조사자의partial은 부모가 별도 HTML 원문으로 이어갔다. 같은 설정의 새 온라인 조사48개 근거·두 기획 전달은1203.719초였으며 등록 자료 재사용 시간과 나눠 제시한다. 이 사례는 역할 분담·독립 대조의 실행 근거이며 별도 역할이 항상 빠르다는 비교 실험은 아니다. Codex 후속은 위임 호출 없이 부모가 직접 완료했다. 역할 파일·packet 준비를 실제 Agent 실행으로 세지 않는다.

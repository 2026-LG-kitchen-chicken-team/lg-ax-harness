# 기획자가 읽는 본문과 자료 보관을 분리

2026-10-17 사용자 결정: 보고서가100쪽을 넘는 문제는 접기만 추가하는 방식으로 처리하지 않는다. 기획자가 실제 판단·작업에 쓸 내용을 선별해 기본 웹과 보고서에 남긴다. 조사 자료를 줄이거나 원문·이력을 삭제하는 결정은 아니다.

## 표시 기준

| 층 | 목적 | 기본 표시·인쇄 |
|---|---|---|
| 기획 본문 | 문제와 기존 기능, 남은 문제, 기획안·선택 이유, 요구사항·적용 전제, 시작할 작업 | 먼저 표시. 실제 결과 상태·중요 조건은 유지 |
| 근거·부록 | 주장별 출처와 원문, 상세 비교·전체 적용 순서·검증 계획, 조사 구성 | 필요할 때 탐색. 기본 보고서 인쇄에서 전체 원문·부록 제외 |
| 고급 진단 | JSON·binding·파일 지문·검토/조사 사건·실행 이력 | 별도 선택. 일반 기획 본문에서 제외 |

본문은 저장된 결과를 코드로 배치한다. 임의 문자 자르기·제품별 정답·새 모델 요약·숨겨진 추가 모델 호출을 넣지 않는다. 제안의 요구사항에는 중요 조건이 있을 수 있어 본문에 보존한다. 처음 할 작업은 저장된 적용 순서의 첫 단계이며 새로운 우선순위를 추정한 것이 아니다. 전체 단계는 선택 상세에서 읽는다. 실측 전 효과, 보류·무효·취소·새 요청과 과거 결과의 차이는 관련 기획 옆에 유지한다.

전체 result/refs/sources와 현재 session/turn/result version·원문 지문은 보관한다. 본문에서 제외한 원문을 조사하지 않은 것으로 바꾸거나 페이지 축소를 분석 폭 축소로 구현하지 않는다. 원문을 저장했다는 사실은 모델이 전량 독해했다는 인증과 다르다.

기본 보고서5~8쪽은 목표이며 강제 고정 페이지나 측정 결과가 아니다. 페이지를 맞추기 위해 폰트를 읽기 어렵게 줄이거나 자료를 삭제하지 않는다. 인쇄시 접기를 무조건 전부 열지 않으며, 부록 전체 출력은 사용자 선택으로 분리한다. 최종 페이지 수는 브라우저·글꼴·용지 설정에 따라 별도 검수한다.

## 원터치 안내 잠정 중단

터미널 한 줄 다운로드와 AI에게 맡기는 원터치 설치 안내를 현재 기본 경로에서 제외한다. 심사위원 ZIP을 받아 사용설명서를 따라 시작한다. 기존 설치 도구·릴리즈 태그는 이력으로 보존한다. ZIP 시작 파일의 uv/Python 준비를 제거한 것은 아니며 이를 준비물에서 명확히 안내한다. 제품 저장소의 기존 공개 예약·개발 저장소 비공개·계정/권한 설정은 이 결정으로 바꾸지 않는다.

## 통합·검증 범위

PR25는 PR23의 후속이므로 하나의 계보로3-way 통합한다. 최신 main의 관찰·결과 연결·런처를 구버전 파일로 덮어쓰지 않는다. 프로토타입의 별도 LLM backend는 출품 실행 경로로 채택하지 않는다. 제품 ZIP에는 manifest의 factory 화면과 기존 관찰 코드만 포함한다.

모델/실행 환경은 실제 AA/Z 증거와 이번 일반 코드·산출물 검사를 분리한다. 기존 Windows MXC 정책 경고나 브라우저 자동 접근 차단을 다른 권한/GUI/모델로 우회해 성공을 만들지 않는다. 촬영·발표물 제작은 이번1~6 작업 범위에 포함하지 않는다.

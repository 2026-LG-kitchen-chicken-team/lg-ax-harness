# 조사 범위 확대와 같은 자료의 모델 비교

2026-10-14 사용자 승인: 조사 범위를 넓히고 Claude 권장 설정까지 확인한다. 이번 단계는 출품 하네스의 조사·상품기획 평가다. 웹팀의 화면과 보고서 HTML은 변경하지 않는다. 이 계획 자체를 실행 완료로 설명하지 않는다.

## 조사와 비교의 구분

빈 catalog에서 냉장고·전자레인지·식기세척기를 각각 새로 조사한다. 공식 사양, 관련 설명서, 제조사 밖 후기, 후속 페이지, 사용 조건, 반례를 계획하고 실제 시도와 남은 범위를 기록한다. 개수만으로 충분성·독립 고객 수·대표성을 판정하지 않는다. 같은 후기의 연속 발췌와 재게시를 다른 고객으로 세지 않는다. 접근 제한을 우회하지 않으며 가능한 조건부 기획과 근거 부족 보류를 구분한다.

세 조사에서 실제 현재 turn의 data_version·dataset fingerprint에 결속된 등록 catalog 전량을 비교 자료로 보존한다. 본문·본문 SHA·출처 메타데이터·정확 모델/문서 범위는 유지하고 source ID의 이름 공간과 해당 참조만 바꾼다. 모든 원 관측과 미등록 자료는 조사 원본에 별도로 남는다. 비교용으로 자료 폭을 줄이지 않는다.

새 비교 원본은 `corpus-L2-seal.json`의 세 파일 SHA·provenance SHA·L2 manifest에 결속한다. source-L2.json에 남은 과거 corpus 메타데이터를 새 비교 원본으로 사용하지 않는다. 기대 제품군과 비어 있지 않은 자료, 동결 설치 manifest의 실제 바이트, 원질문 SHA를 준비·발송 전에 검사한다.

## 실행 조건

- 현재 source L2 manifest: `9939e2472091eaf8f017e47eb1297a3b7e57beb48870c17307b9e6884db5edc5`. 냉장고 최초 새 조사는 L1이었으며 L2 실행으로 바꾸지 않는다. L2는 조사 이력의 미리보기를 전체 보고로 사용하던 코드를 보완한 버전이다.
- 실제 부모 업무 입력 최대 14회: 새 조사 3회, 같은 자료의 Codex 3회, Claude 후보 최대 5회, 선택 후보의 반복·다른 제품군 최대 3회. 이전 누적 77회는 보존하며 자동 재발송은 0회다. 사용하지 않은 준비와 계측·원본 재읽기는 새 업무 실행으로 세지 않는다.
- 업무 동시 실행은 1개다. Codex는 실제 native 실행, Claude는 로그인된 유료 Desktop Code GUI를 사용한다. 자체 모델 API 실행기나 별도 API 키를 추가하지 않는다.
- 조사와 최종 전달의 안전상한은 1800초다. 마지막 90초는 수집 종료·최종 전달 준비에 사용한다. 1800초를 성능 목표나 모든 backend의 강제 중단 인증으로 설명하지 않는다. 과거 300/600초 진단은 해당 시점 이력이다.
- 비교 입력은 같은 제품군 원질문·설치·원문 전체·저장/전달 조건을 사용하며 온라인 조사를 하지 않는다. 부모 단독으로 처리하고 추가 Agent·외부 메시지·소스 변경을 하지 않는다. 기본 report:false이며 HTML/PDF/DOCX/XLSX·이미지 생성은 제외한다.
- Codex 기준 후보는 gpt-6-astra/low다. Claude 후보는 실제 GUI에 제공되는 Opus 5.5 중간/높음, Sonnet 5.5 중간/높음, Fable 5.1 중간이다. 별도 결제나 접근 차단이 발생하면 실제 상태를 기록하고 해당 후보를 실행 완료로 바꾸지 않는다. 준비 화면과 실제 trace의 모델을 구분한다.

## 인수와 선택

목적·모델/버전·불편→기능→제안·출처 의미/맥락·미확인/보류·최종/저장 정합·검증 계획의 7축을 독립적으로 검토한다. 내부 14점은 공식 심사점수나 완성도 비율이 아니다. 실제 원문에 없는 사실·다른 모델의 근거 전이·근거 없는 안전/효과 확정·현재 저장/최종 불일치는 핵심 결함이다. 기획 전제에 영향을 주지 않는 국소 문구와 향후 검증 계획의 상세 부족은 따로 기록하고 원본을 보존한다.

조건부 업무 인수는 핵심 결함 0, 적용 축 0점 없음, 12/14 이상, 실제 현재 검토·저장·전체 선택 원문·web_result·finish·종료 export·최종 completion 문구의 정합을 요구한다. 근거 부족에 대한 정당한 보류는 안전한 대응일 수 있지만 상품기획 해결 완료와 별도 집계한다.

설정·시각을 가능한 범위에서 가린 품질 packet을 검토한다. 산출물 양식이 제공사나 실행 시간을 드러낼 수 있어 완전한 맹검으로 부르지 않는다. 실제 읽기 범위·판정·근거 지문·미확인 사항을 남긴다. 같은 자료의 품질 차이가 작은 후보들 중 실제 관측 시간이 짧은 후보를 선택하고, 반복 및 다른 두 제품군에서도 확인한다. 작은 표본의 운영 권장 범위이며 통계적 동등성이나 모든 질문에서의 우위를 주장하지 않는다.

## 시간·사용량·원본

새 조사부터 종료까지의 시간과 이미 확보한 자료의 기획 시간을 분리한다. Codex는 실제 마지막 답변·turn.completed·process exit를 구분하고, GUI는 실제 사용자 입력→assistant end_turn을 사용한다. GUI에 process exit가 관측됐다고 가정하지 않는다. Tool 사이 시간에는 모델·네트워크·실행기 대기가 섞이므로 전부 추론 시간으로 부르지 않는다.

관측 usage의 제공사별 필드와 coverage를 보존한다. 캐시나 reasoning 하위 항목을 중복 합산하지 않으며 unknown을 0으로 바꾸지 않는다. 전체 backend·청구 및 개발 Agent 사용량은 실제 관측되지 않으면 unknown이다. 사람 대비 절감률은 평가하지 않는다.

불완전 GUI 시도와 평가 helper 예외도 원본·현재 저장·시각·실패 영수증으로 보존한다. helper 실패를 native 실패나 성공으로 대신 판정하지 않는다. 실제 중단 관측 전에는 runtime을 이동하거나 다음 업무를 발송하지 않는다. 물리 Esc는 해당 turn Computer Use를 중단하며 자동 재개하지 않는다.

원문·DB·실행 trace·인증은 Git 제외 비공개 보존한다. 공개 기록에는 비개인 집계·지문·실제 명령 결과와 한계를 남긴다. 제품 릴리스에는 출품 코드·Skill·Tool·설치·잠금·LICENSE/NOTICE만 포함하고 평가 원문과 개발 체계는 제외한다.

## 실제 비교 조건의 보완 기록

Opus 5.5 높은 추론의 첫 실행은 부모 단독 입력과 달리 `product-evidence-reviewer`를 실제 1회 호출했다. 이 결과는 검토 역할의 관측 사례로 보존하며 순수 모델·추론 수준의 시간 순위에서 제외한다. 사용자 입력부터 실제 end_turn까지 685.907초, 검토 Tool의 공개 호출→반환 구간은 125.067초였다. 후자는 backend 실제 지속시간이나 강제 실행상한 인증이 아니다.

그 후 격리된 평가 프로젝트의 `.claude/settings.local.json`에 `permissions.deny:["Agent"]`를 설정하고 새 세션을 사용한다. [Claude Code 공식 권한 문서](https://code.claude.com/docs/en/permissions)의 Tool 거부 방식이며 출품 원본·사용자 전역 설정에는 적용하지 않았다. 정책 바이트 SHA를 준비·발송·인수에 결속하고 실제 trace의 Agent/Task 요청도 확인한다. 설정 존재와 실제 Agent 요청 0은 별도 근거다.

동일 정책을 적용한 Sonnet 중간·높음과 Opus 높은 추론의 부모 단독 실행을 비교한다. 첫 Opus 중간은 당시 Agent 거부 정책이 없었으나 실제 Agent 요청은 없었다. 같은 코호트라고 가정하지 않고 핵심 기획 전제 오류를 포함한 결과로 보존한다. 총 14회 입력 상한 안에서 Fable 5.1 중간의 예정 입력을 Opus 높은 추론의 부모 단독 재확인에 사용한다. Fable의 이용 가능 화면은 확인했지만 실행 품질이나 순위를 판단하지 않는다. 역할 혼입 실행도 전체 사용량·시간·실패 장부에서 제외하지 않는다.

## 마감과 해석 범위

실제 부모 입력 14회를 모두 발송하고 최종 종료까지 보존했다. 이전 77회와 누적 91회이며 자동 재발송은 0회다. 최종 판정·시간·관측 usage와 운영 권장은 [L2 비교 기록](../validation/model-comparison-L2-20261014.md) 및 [설정 결정](../decisions/claude-runtime-20261014.md)에 남긴다. 이 문서의 후보 목록을 모든 후보의 실행 완료로 해석하지 않는다.

새 세션·빈 업무 runtime과 동결된 설치·catalog를 사용했지만 공유 프로젝트의 scratch 파일, 제공사 캐시, 실행 순서까지 모두 초기화한 cold 실험은 아니다. 같은 모델의 반복 시간 차이도 보존한다. 운영 권장은 이번 제품군·원문·전달 조건의 인수 결과이며 통계적 동등성, 모든 모델 중 최적, 모든 질문에서 같은 시간이나 품질을 보장하지 않는다. 원문의 폭과 등록 건수는 코드로 집계하고 AI의 서술 건수와 차이가 있으면 정형 집계를 사용한다.

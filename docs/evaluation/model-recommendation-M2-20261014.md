# 검증한 설정의 운영 권장 — L2 이력과 M2 인수

2026-10-14 권장은 **Codex gpt-6-astra/low를 주 실행 설정**, **Claude Desktop Code Opus5.5/UI 높음을 대체 실행 설정**으로 둔다. Claude에서 근거 의미·서비스 조건이 중요한 결과는 선택 근거 검토 경로를 사용하고 원문과 최종 저장 결과를 확인한다. 이것은 실제 검증한 명시 집합이며 숫자 범위의 모든 모델이나 추론 수준을 권장하지 않는다.

[L2 비교](../validation/model-comparison-L2-20261014.md)는 같은219개 등록 corpus·세 제품군의 조건부 기획 인수 근거다. Astra/low 고정자료3회는6분51초~10분44초(중앙7분31초), Opus/high 부모 단독4회는7분54초~11분49초였다. Opus/medium·Sonnet/medium은 당시 각각 국소 의미 오류·부분 독해로 미충족이었다. Sonnet/high 전자레인지1건은 인수했지만 권장 범위를 넓힐 충분한 반복/제품군 근거가 아니다. 다른 Codex 모델 전체를 같은 corpus로 재순위화한 비교도 아니다.

[M2 인수](../validation/quality-role-web-integration-20261014.md)는 새 동일 소스의 냉장고 정상/후속·미확인 치수·접근 거절·취소 및 Claude 선택 역할 진단이다. Astra/low 정상532.531초·후속628.422초에서 현재 전달과 중요 의미 결함 없음이 확인됐다. Claude Opus/high 정상587.934초·후속275.234초는 같은 국소 P2 1건이 남았고, 선택 역할855.788초 결과는 중요 P1/P2 없이 반환·최종 반영이 확인됐다. 따라서 Claude 부모 단독을 완벽한 의미 검증으로 표현하지 않는다.

권장의 이유는 **검증된 자료 범위를 유지하며 기획·근거·조건·저장·최종 전달을 재현했고, 실제 측정 시간이 확보된 설정**이라는 점이다. 빠른 결과 하나로 정한 전 모델 최적값이나 제공사 사이의 동일 추론량 비교가 아니다. 역할은 실제 품질 보완 기여가 있으나 두 환경의 단일 역할 진단은 부모 단독보다 시간이 길었다.

Codex 명령은 설치된 업무 폴더에서 다음을 사용한다.

```powershell
codex --search --model gpt-6-astra --config 'model_reasoning_effort="low"'
```

Claude는 설치된 업무 폴더를 Desktop Code로 열고 실제 UI 모델 **Opus5.5**, 노력 **높음**을 선택한다. 실제 trace의 `claude-opus-5-5`와 UI 설정은 확인했지만 backend effort·전체 자식/청구 usage는 unknown이다. Desktop 성공은 독립 CLI 인증의 증명이 아니다.

온라인 조사 시간은 고정자료 기획과 구분한다. 자료/후기의 폭을 줄여 시간 순위에 맞추지 않는다.1800초는 안전상한이며 성능 목표가 아니다. 제출 영상은 자연 완료 기록을 편집하고 대기 구간/배속을 표시한다. 현장 발표·영상 합계10분과 AI 업무 자체 실행 시간을 혼동하지 않는다.

모델 접근 가능성은 실행자 계정/버전에 따라 달라질 수 있다. 위 설정을 선택할 수 없는 환경은 동일한 정상·후속·예외 입력과 원문/전달 기준으로 별도 검증 후 기록하며 자동으로 동등 지원으로 승격하지 않는다. 과거 [2026-10-13 탐색 계획](model-recommendation-20261013.md)의 미확정 상태는 해당 시점 이력으로 보존한다.

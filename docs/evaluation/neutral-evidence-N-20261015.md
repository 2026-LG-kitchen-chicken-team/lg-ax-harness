# 중립·조언 근거 판정 — N, 2026-10-15

이 문서는 원문과 공개 후보/저장/최종 전달만 대조하는 독립 평가 기준이다. 숨은 추론, 특정 제품·질문·source_id 정답표, 키워드 기반 수용 규칙을 사용하지 않는다. 지침·형식 검사는 실제 native 의미 회귀의 통과 근거가 아니다. 아래 반례는 신규 합성 의미 경계 사례이며 실제 고객·제품 자료가 아니다. 동결 M 원문·입력·helper는 변경하지 않는다.

평가자는 같은 선택 자료와 현재 저장 버전에서 다음 항목을 각각 판정하고 원문 구간·주장 위치·영향을 남긴다. 별점이나 전체 어조 대신 의미절별로 주어·대상·시점·조건·실제 영향을 대조한다.

동일 자료의 원래 A→F 후속은 각 현재 버전의 후보·저장·최종문을 따로 평가한다. A의 문제를 F가 고쳤다면 A를 소급 통과시키지 않는다. 위의 첫 두 오류를 없애기 위해 모든 기획을 빈 pains/held로 만든 경우 세 번째 기준의 비퇴행도 통과해야 한다. 개수·처리 상태·형식 통과는 의미 품질의 대용 지표가 아니다.

최종 기록은 평가한 입력/버전·실제 전달 여부·기준별 판정·근거 위치·남은 한계를 포함한다. 수행하지 않은 native 회귀는 not_run, 관측하지 못한 전체 호출/비용은 unknown으로 남기며 이 문서 작성으로 통과했다고 기록하지 않는다.

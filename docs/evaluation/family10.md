# 제품군 일반 입력10개

동결50개와 별도 버전·별도 집계다. 공식 심사문항이나 미사용 검증셋이 아니다. 모델코드 없는 일반명·축약명·후속 범위 유지·모델 선택·보유 제품 미확인·일반화 함정을 확인한다. 채점은 regression50의7축을 쓰되 제품군 요청은 전체 저장 model_scope와 모델별 근거 귀속을 확인한다. 정당한 보류/확인 요청은 제안이 없다는 이유만으로 실패하지 않는다. native 실행 여부는 validation 보고에 별도 기록한다.

- **G10-01** (family): 냉장고에서 사용자가 불편해하는 점을 찾아서 개선 아이디어 한 개만 제안해 줘.
- **G10-02** (family): 전자레인지 사용 불편을 실제 리뷰에서 찾아서 개선 아이디어 한 개만 제안해 줘.
- **G10-03** (family): 식기세척기를 쓰면서 불편한 점을 찾아서 개선 아이디어 한 개만 제안해 줘.
- **G10-04** (followup; 직전 G10-01): 냉동실 문제는 빼고, 같은 냉장고 자료에서 다른 개선 아이디어 한 개를 찾아 줘.
- **G10-05** (narrow; 직전 G10-04): 그중 B502S33만 보자. 냉동실 문제를 제외한 조건은 유지해서 다시 판단해 줘.
- **G10-06** (generalization): 냉장고들은 다 청소가 불편하다는 얘기를 들었어. 실제 근거로 확인하고 개선안을 제안해 줘.
- **G10-07** (alias): 식세기 건조가 불편한 사람들을 위해 어떻게 개선하면 좋을까?
- **G10-08** (owned_unknown): 우리 집 전자레인지에 25cm짜리 그릇이 들어가고 안전하게 돌아가는지 알려줘. 모델명은 지금 몰라.
- **G10-09** (owned_unknown): 우리 집 냉장고 선반에 큰 용기가 들어갈지 계산해줘. 냉장고 외형 폭만 알면 되지? 모델명과 내부 치수는 몰라.
- **G10-10** (ambiguous): 주방 가전 사용 불편을 줄이는 아이디어를 만들어 줘.

# v7.4 최종 원본의 제한 회귀 계약

2026-10-12. 원문/AI 해석·보류 근거·후기 맥락/집계·관측 시간 수정 후 동일 제품 원본을 동결한다. v7.3 선행 실행은 별도 보존하고 후기 문맥 사전 점검·취소 대상 전달 지침을 보완한 v7.4로 아래 입력을 다시 평가한다. 평가 기대값은 제품 prompt/설치물에 넣지 않는다. 공식 심사 문제가 아닌 팀의 진단 입력이다. 제품의 기본 catalog는 비어 있고, 저장 근거 재사용 시험만 공개 실제 자료 lg-kitchen-v4를 명시적으로 설치한다.

### 취소 분기의 추가 선언

R05는 실제 turn 없는 조사 보류로 종료했고 최종 pointer를 파일 링크로 전달해 실패했다. 사전 조건에 따라 R06은 미실행으로 보존한다. 취소 기능을 확인하기 위해 C01 `그 접시 적합성의 추가 확인 요청은 취소해줘. 지금까지 남긴 내용은 보관해줘.`를 **추가 실행 전에** 선언한다. 실제 R03의 needs_input turn과 같은 native 대화에서 실행하며 원래 R06의 성공으로 대체하지 않는다. 동일 v7.4 설치물·420초·자동재실행0·동시 최대2를 유지한다. 총 계획은 기본13개와 추가1개, 실제 실행/미실행 수는 별도 집계한다.

## 판정

- 최종 JSON 블록 전체를 엄격한 JSON 파서로 확인한다. 관대한 객체 추출 통과만으로 여분 괄호·형식 오류를 통과시키지 않는다.
- 원질문 전체·사용자 제약·정확 모델/문서·자료 지문·실제 native ID·최종 텍스트와 당시 DB/export를 대조한다. 미실행/오류/timeout·거절 후보를 보존한다.
- 의미7축은 목적/제약, 정확 모델/버전, 불편→기능→제안, 출처 의미, 미확인/보류, 최종·저장 정합, 실행/검증 계획이다. 각0–2점 또는 사유 있는 null, 적용축 환산12/14 이상·0점 없음·중대 오류 없음으로 판정한다. 상태가 보류라는 이유만으로 실패 또는 성공으로 정하지 않는다.
- 중대 오류: AI 해석/저장 요약을 공식 직접 문구로 귀속, 맥락을 뒤집은 인용·후기 일반화, 근거 없는 적합/안전/효과 확정, 기존 기능의 신규 기능 포장, 사실의 출처 전달 누락, 최종/export/DB 불일치.
- 직접 인용은 실제 보유 support_quote의 연속 구간이다. source_fact basis는 모델의 신고이며 의미 인증이 아니다. 긍정·조건·유보와 고유 후기 ID/분모, 발췌 범위를 검토한다.
- 실행시간은 외부 실제 입력→최종 종료 기록이다. AI 자체 추정·저장 시점을 전체 시간으로 쓰지 않는다. 계획된 효과는 실제 실적으로 쓰지 않고 사람 비교는 제외한다.
- 취소는 실제 cancel_turn·export·SQLite·기존 후보 보존을 확인한다. 로컬 쓰기 차단과 native/backend 종료를 구분하며 직접 종료 증거가 없으면 backend_stop_observed=null이다.

## 사용량

Codex는 같은 native 세션 마지막 누적값을 한 번만 합산하고 후속은 확인된 이전 종료값의 차분으로 계산한다. Claude는 실제 main turn의 고유 assistant message ID별 비캐시 입력+cache creation+cache read와 output을 집계한다. 실패·수정도 포함한다. 원문 로그/DB/개인 경로는 Git 제외하고 지문·비식별 수치·검토 사유를 공개한다. 전체 backend/sidechain/청구·비용·절감률은 입증 없으면 unknown이다. 관찰 수집·검사는 일반 코드이며 제품 실행에 토큰 감사용 Agent를 추가하지 않는다.

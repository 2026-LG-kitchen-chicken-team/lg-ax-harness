# 토큰 절감 반영과 시연 표시 기준

2026-10-12 최신 근거는 [토큰 가산점 기록](../validation/token-bonus-20261012.md)에 정리한다. 아래 비율은 과거 버전의 별도 표본이며 최신 절감률로 재사용하지 않는다. 최종 v7.4의 실제 입력·출력·캐시·시간·실패/보류 및 품질 한계를 함께 표시하고 전체 backend/청구·비용·일반 절감률은 미측정으로 둔다. 사람 대비 비교는 제외한다.

2026-10-10. C06의 구현·관측·미검증 범위를 정리한다. 개발 평가 역할은 `evaluator` + `evaluate-harness`이며 독립 `reviewer`가 근거를 대조한다. 출품 실행마다 토큰 분석 Agent를 추가하지 않는다. 이 문서 작성에는 신규 출품 AI 입력·유료 호출이 없다.

## 별도 관찰 화면의 사용량 계약

표시 필드는 `입력 전체`, `그중 캐시 입력`, `비캐시 입력(차이)`, `출력 전체`, `그중 reasoning`, `갱신 시각`, `관측 범위`다. null/미관측은 `— / 미측정`, 종료 전 마지막 snapshot은 `부분 관측`으로 표시한다.

- 입력 전체 = 비캐시 입력 + 캐시 입력. 입력에 캐시를 다시 더하지 않는다. reasoning도 출력의 일부이며 다시 더하지 않는다.
- 같은 native 세션의 snapshot은 최신 유효 누적값을 표시하고 더하지 않는다. turn별 사용량은 같은 ID·확인된 CLI 버전·역행 없는 누적값에서 이전 종료값과의 차이로 계산한다. 확인되지 않은 경우 차이는 미측정이다.
- native 세션/turn 집계와 호출자가 보고한 업무 `record_usage`는 출처·범위가 다르다. 두 값을 중복 합산하거나 업무의 unknown을 native 수치로 덮어쓰지 않는다.
- 명령 수·stdout bytes·token_count 이벤트 수는 모델 backend 호출 수가 아니다. Skill/Tool별 토큰도 실제 범위별 관측이 있을 때만 표시한다. 일반 코드 Tool의 모델 사용량을 임의0으로 인증하지 않는다.
- 전체 부모·자식·실패·수정 호출과 청구가 빠지면 `부분 관측`이다. 모델/가격/계약이 확인되지 않은 비용, Codex 크레딧 환산, 전체 예산 잔액은 표시하지 않는다.
- Langfuse 등의 제공사 모델별 비용 계산에 세션/turn 합계를 단일 generation으로 넣지 않는다. 현 단계 제안은 native 집계를 별도 metadata/표로 보존하는 것이다. per-generation usage와 배타적 bucket 매핑이 검증되기 전 자동 비용 계산을 근거로 쓰지 않는다.

실제 수집·별도 도구 연결·라이브 표시 인수는 [관찰 계획](../plans/observability-viewer.md)을 따른다. 평가 파서는 종료 후 기록을 읽는다. 별도 observer의 실제 본 실행 tail과 Langfuse 연결은 [별도 인수](../validation/observer-langfuse.md)했으며 완전한 호출별 청구 수집은 아니다.

T06a의 compact·BOM·최종 전달과 T06b의 제한된 반복/신규 비교를 수행했다. T06c 전체 청구와 일반화, T06d 완전한 on/off 반복은 별도 열린 항목이다. 사람 비교는 제외한 과거 계획이다. 지시문 공격 의미의 조건 결합 및 후기 개별 모델 연결 결함을 남겨 품질 희생 없는 일반 토큰 개선을 다음 설계에 포함한다.

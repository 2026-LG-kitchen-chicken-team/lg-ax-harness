# 수정 마감과 한 차례 평가

2026-10-11. 사용자 요청에 따라 웹 절별 출처, 경험/선호/기대, 실제 평가 입력의 제약 누락을 닫는다. 기존 실패·timeout은 유지한다. 이번 자료 조사는 3모델 범위로 종료하며 새로운 검색·자료 확보를 이 단계의 완료 조건으로 두지 않는다. 미확보 청소 불편/내부 치수/효과는 보류다.

제품 v5.5와 기존 실제 v3 자료를 동결한다. 신규 작성 입력 F01~F04 최대4개, 동시2, 입력당420초, 자동 재실행0. 실패·timeout도 시도 횟수에 포함한다. F03이 전달 실패하면 같은 대화의 F04는 not_run으로 남기며 다른 질문을 대체하지 않는다. 시작 marker·동결 source/runner/질문/자료 SHA·전체 관측 사용량을 private .harness에 보존한다. 이번 입력은 비맹검 진단이며 독립 held-out·수백 심사 질문의 일반 성공률이 아니다.

| 입력 | 업무·의미 인수 |
|---|---|
| F01 B502S33 상한1 | 현재 잘 사용함/넉넉한 제품 선호/좁음·2인 수용을 구분. 냉동실 넉넉함 만족으로 전이 금지. 새 부품 없는 근거 있는 조건부 안내 또는 보류 |
| F02 S836GBB122 상한1 | 홈바 사용 편의와 도어 청소 기대 구분. 청소 불편/실제 청소 효과/360mm 선반 간격/20% 절감은 자료 없으면 보류. 제안0 허용 |
| F03 T876MQQ012 상한2 | 적재 차광·식재료 확인 절차, 선반 조작/내부 청소의 p17/p17–18/p19 구분, 정확 모델 사양과 공용 설명서 한계 유지. 기존 선반 기능을 신규 기능으로 제출하지 않음 |
| F04 F03 같은 native/session 상한1 | 위치/접기/높이 변경 금지, 새 부품 금지 유지. 과거 후보/출처/검토 불변·prior 연결·제약 반영. 가능한 조건부 안내 또는 근거 부족 보류 |

계약 인수는 실제 final→receipt→SHA→export→현재 DB와 실제 질문/모델/제약/자료/코드 지문을 대조한다. 의미는 목적/제약, 모델/범위, 불편/긍정, 기존 기능, 제안, 미확인/출처, 완료/보류의7축 각0~2로 독립 검토한다. 만점도 원문 진위·시장·실물 효과·미래 일반화를 뜻하지 않는다. 전체 청구·사람 시간·비용/토큰 절감은 미입증이다. 새 baseline이나 웹 모델 실행은 추가하지 않는다.

웹 절 수정은 별도 code 회귀에서 절별 URL/위치/인용/새 버전 보존, 혼합/다른 절·legacy 혼합 import 거부, HTTP hash 절 오인 차단을 검증한다. 이는 신규 native 웹 재관측 성공과 구분한다. 이전 WEB-02의 제약 누락 실패는 보존하고 새 build_web_prompt 검사로 누락을 막는다.

완료 조건: 세 수정의 관련 코드 검사와 자산/설치 검사 통과, 계획한 AI 입력의 완료/실패/not_run 결과 기록, 독립 검토, 자료 조사 종료·외부 의존 분리. 추가 정확성·절감 목표를 충족할 때까지 반복하지 않는다. 이후 관찰 화면·실제 발표/영상 준비로 작업 단계를 전환한다.

# 충분한 검증 뒤 모델·추론 수준 권장

최신 사용자 결정: 특정 모델 하나나 추론 수준을 성급하게 고정하지 않는다. 실제 테스트한 명시적인 모델/effort 집합과 검증한 업무 범위를 권장한다. 숫자 구간의 모든 모델을 지원·권장한다고 설명하지 않는다. 공식 지원·계정 접근·실제 실행·품질·속도는 각각 별도다.

## 현재 판정

최종 권장 범위는 **미확정**이다. 최신 [실행/제한](../validation/web-ready-harness-20261013.md)에서 source H와 I를 분리한다. H는 Codex gpt-6.1-sol/medium·Claude GUI Sonnet5.5/중간 각각 세 제품군의2회 반복을 완료했지만, Claude 냉장고 반복9/14·중대2와 다른 출처 결함이 남았다. 현재 I의 같은48자료 MW는 Codex medium436.688초/13점, Claude 중간401.185초/12점, 높음437.531초/12점이다. 각1회와 source 결함이 있어 아래 동등 품질 gate를 충족하지 못한다. Claude GUI label은 관측했지만 backend 연산량은 unknown이며 중간 설정은 복구했다. Codex medium은 **재현용 비교 기준**으로만 쓰고 최적 모델 추천으로 설명하지 않는다.

온라인 실제 조사1754.640초는 등록110후기+2사실·네트워크/페이지 접근·미등록 공식 상세 근거의 다른 업무 범위이며 고정48자료와 모델/effort 속도 비교로 쓰지 않는다. 원문 폭을 줄여 목표 시간을 맞추지 않았고, 코드 Tool 밖 시간을 전부 추론으로 귀속하지 않는다. 최종 권장에는 출처 의미와 실제 검증계획의 보완이 먼저 필요하다. 과거 A/C/F의 시간·점수는 해당 소스의 탐색 이력이며 현재 I 반복 근거로 합산하지 않는다.

## 단계와 판정 기준

1. 실제 계정에서 가능한 모델/effort를 기록하고 설치·자료·질문·도구·출력 기준을 동결한다. 모델 alias는 실제 resolved model과 구분한다.
2. 후보 선별 뒤 냉장고·전자레인지·식기세척기의 서로 다른 요청을 유지한다. 긍정/불편/조건/반례/문서 범위를 줄이지 않고 같은 자료·질문으로 모델/effort만 비교한다.
3. 후보별·제품군별 반복 최소2회를 초기 계획으로 삼고, 출처 결함·큰 시간 변동·상충 결과가 있으면 관련 입력을 더 검증한다. 이 횟수가 통계적 충분성이나 전체 심사 입력 대응을 인증하지 않는다.
4. 정상 기획과 확인/보류/웹 실패/취소/설명 후속을 구분한다. 개발 중 반복한 입력과 별도로 미사용 문구·조건을 검증하고, 그 질문에 맞춘 정답 분기를 코드에 추가하지 않는다.
5. 시간/모델/effort를 점수 근거로 쓰지 않는 독립7축 의미 검토를 수행한다. 저장·export·최종 전달·원문·실제 화면 검수·실패/중단을 함께 대조한다.
6. 품질12/14 이상·적용 축0 없음·중대 오류0·현재 저장/전달 정합이 필요하다. 평균 손실≤0.5, 입력별≤1, 새 중대/출처/전달 결함 없음의 운영 조건을 모두 충족한 후보 사이에서 자연 완료시간과 전체 관측 usage를 비교한다. 빠른 단일 성공만 선택하지 않는다.
7. 중앙값·범위·표본수·실패 분모·캐시/순서·네트워크·실행 환경을 기록한다. 안전 종료 표본은 중단으로 남기며, 도구 밖 시간을 전부 추론 시간으로 쓰지 않는다. 제공사 사이 effort 이름이 같은 연산량이라는 전제도 두지 않는다.
8. 검증한 명시 집합만 권장하고 업무/자료/환경·한계·검증일을 붙인다. 일반 코드 검사가 native 품질·권장 범위를 인증하는 것은 아니다.

과거18입력은 당시 이력이다. 이번 추가 단계는 G5+H14+I5=24/24, 이전21을 보존해 누적45, 잔여0/자동재발송0으로 마감했다. 카운터를 초기화하거나 추가 모델 입력을 자동 시작하지 않는다. 현재 I의 native 취소·후속과 웹 화면 검수는 not_run이다. source별 완료/실패·검토 경계는 [웹 전달 검증](../validation/web-ready-harness-20261013.md)을 따른다. 충분성·출처/전달 결함 조건 미충족을 모델 권장 완료로 바꾸지 않는다.

공식 기능 확인: [OpenAI GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol), [Claude 모델/effort 설정](https://code.claude.com/docs/en/model-config)을 2026-10-13 열어 확인했다. API 설명을 이 하네스의 자체 API 실행기 도입이나 해당 계정의 모델 접근 증명으로 바꾸지 않는다.

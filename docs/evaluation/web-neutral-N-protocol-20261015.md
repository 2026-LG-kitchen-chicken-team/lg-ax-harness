## 자동 연결 증거

실제 업무 전 프로젝트 로컬 viewer/관찰 설치를 수행하고 source·설치·설정·기준점·CLI/UI 버전을 기록한다. 새로운 export가 만들어지는 실제 native 실행 중에는 root가 viewer open/build/hook 명령이나 trace importer를 직접 호출하지 않는다. 자동 생성 파일과 실제 브라우저의 열림·현재 결과·후속 갱신을 확인한다. `opened_sessions` 기록만으로 브라우저가 실제 열렸다고 인증하지 않는다.

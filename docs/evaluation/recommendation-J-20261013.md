# 모델·추론 조합 선정: J 비교 계획

[새 승인 결정](../decisions/recommendation-J-20261013.md)을 따른다. 모델 이름의 상위/신규 여부만으로 권장하지 않는다. 기존45입력과 분리한 최대32입력의 새 단계다. 추가 실행을 실제 보내기 전에 원자 장부에 등록하며 실패·후속 포함/자동 재전송0을 유지한다.

## 후보와 계정 접근

- Codex 로컬0.162.0 cache: gpt-6.1-sol, gpt-6-astra, gpt-6-sol, gpt-6-luna, gpt-5.6-sol의 표시/지원 effort를 확인했다. cache는 실제 모델 응답·접근 인증이 아니다.
- 초기 screen 후보: 6.1-sol low/medium/high, 6-astra low/medium, 6-luna high, 6-sol medium, 5.6-sol medium. 같은 MW48로 각1회, 일단8조합이다.
- Claude: GUI에서 Sonnet5.5/중간·Max를 확인했다. Sonnet5.5 중간/높음·Opus5.5 중간/높음과 GUI에서 확인한 상위 후보1개를 screen 후보로 삼는다. 목록/실제 응답이 미확인인 조합은 준비/대기이며 실행·지원·권장으로 쓰지 않는다. GUI를 CLI로 대체하지 않는다.
- OpenAI [모델 문서](https://learn.chatgpt.com/docs/models)·[설정 참조](https://developers.openai.com/codex/config-reference), Claude [모델/effort 문서](https://code.claude.com/docs/en/model-config)를2026-10-13 확인했다. 공식 지원, 계정 접근, resolved model, 실제 결과를 별도로 기록한다. provider effort 이름은 동일 연산량이 아니다.

## 동일 자료·순서

고정 실제 평가 corpus112(후기92+사실20)의 FR28/MW48/DW36 범위를 유지한다. source J·질문 canonical 문자열·catalog SHA·설정·출력 계약을 먼저 동결한다. 가용 profile를 MW48 한 번씩 screen하고, 제공사별 품질 통과 finalist1개를 FR/MW/DW 각각2회 확인한다(screen의 같은MW1회를 포함할 수 있다). 새 문제가 있으면 관련 표본의 제한된 재확인만 잔여 상한에서 수행한다. 고정 자료에서는 live웹을 호출하지 않는다. 새로운 live 조사/보존 원문 분석은 별도 사례이며 속도 비교와 합산하지 않는다.

환경상 최대3개의 독립 Codex job와1개의 GUI 화면을 사용할 수 있으나, **J의 시간 비교는 부모 업무 동시1·순차 실행**으로 수행한다. 화면 입력은 한 작성자가 처리한다. 문서/코드 검사를 병행했는지, 캐시/순서·failed shell/Tool/native·실제 마지막 메시지/end_turn/process exit를 각각 남긴다. 후보 선별과 반복 순서는 기록하고 표본 시간을 채점 근거로 쓰지 않는다. 같은 소스의 전체 비교군 실행을 확인한 뒤 최종 순위를 판정한다.

## 품질 먼저

내부7축/14점(목적·모델/버전·불편→기능→제안·출처 의미·미확인·최종전달·실제 검증계획)으로 독립 평가한다. 공식 심사100점/완성도%가 아니다. 제공사/시간을 가린 candidate ID 사본을 가능한 범위에서 사용하고 원문/DB/web/final은 감사 시 대조한다. 완전blind를 가정하지 않는다.

Critical는 잘못된 모델/안전·권한·원문 변조·현재버전/취소 불일치·수행하지 않은 실행 완료 주장이다. Moderate는 핵심 결론을 바꾸는 출처/조건/긍정 분류·검증계획·실패 근거 오류와 주변 설명 오류를 구분한다. Minor는 결론에 영향 없는 표현/가독성 보완이다. 출처를 달았다는 형식 검사만으로 의미를 통과시키지 않는다.

권장 gate는 각제품군 n2·12점이상/적용축0없음/중대0/현재전달정합을 요구한다. 동일 baseline 대비 평균손실≤0.5/입력별≤1와 새 핵심 출처/전달 결함없음을 확인한다. 주변 moderate/minor는 제한과 영향 판정을 명시하며 전체 의미 인증으로 바꾸지 않는다. gate 미충족이라도 준비 범위·비교 기준은 보고하되 가장 빠른 실패를 추천하지 않는다.

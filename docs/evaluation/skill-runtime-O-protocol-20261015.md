# O 단계 — 지침 로딩·선택 호출·같은 소스 실행·로컬 CI

2026-10-15 사용자의 문제 1~6 보완 및 명시/자연어 Skill 호출 추가 지시를 수행한다. 이전 N 단계는 6/6·누적 111로 보존한다. 새 단계는 이전 실패를 지우거나 같은 요청을 무제한 반복하는 절차가 아니다. main 병합·새 제품 릴리즈·촬영 확정·메일 발송은 이번 범위에 넣지 않는다.

## 구현

1. 과도했던 QN77 P2 판정을 철회하고 비차단 국소 표현 의견으로 정정한다. 에이전트의 기획 선택을 임의 정답과 대조하지 않는다.
2. 필요한 메인/Skill 지침을 실제 본문·경로·해시와 함께 반환하는 `get_work_instructions`를 구현한다. 반환과 모델 이해를 구분하고, 같은 해시가 문맥에 있다는 신고는 별도 상태로 기록한다. 지침 응답과 근거 응답을 나눠 원문 전달량을 줄이지 않는다.
3. 자연어 자동 선택을 기본으로 유지하고 Codex `$skill-name`·`/skills`, Claude `/skill-name`을 선택적으로 안내한다. Claude 서브에이전트는 자연어 위임이나 `@` 선택기이며 Codex에 확인되지 않은 `@agent` 문법을 만들지 않는다. 모든 Skill/역할을 항상 실행시키지 않는다.
4. GitHub Actions 계정 문제와 무관하게 실행할 로컬 CI를 추가한다. 실제 명령·종료 코드·도구 버전·소스 지문·빌드 전후 차이를 기록하며 실패 후에도 후속 검사 결과를 모은다. Windows 실행으로 Ubuntu 통과를 주장하지 않는다.

## 실제 실행

최종 통합 소스 하나를 고정해 Codex와 유료 Claude Desktop Code에 각각 설치한다. 등록 자료 219개(후기 발췌 87개·사실 132개)를 유지하며 선택 제품군 FR56/MW82/DW81 전체를 전달한다. 이 자료가 고유 고객 수나 시장 대표성을 보증한다는 뜻은 아니다. 원본·DB·로그·인증은 Git 밖에 둔다.

새 부모 입력 예상 14회, 상한 16회, 자동 재발송 0회다. 불확실 발송도 사용으로 계수한다. 한 설치에서 업무를 동시에 실행하지 않으며 모델 비교의 순차 실행 조건을 기록한다. 지침 단독 진단 2회, 모델/추론 냉장고 비교 5회(Codex Astra low/medium·6.1-sol medium, Claude Opus 5.5 UI 중간/높음), 각 환경에서 선정한 조건의 전자레인지·식기세척기 4회, 후속/미사용 질의 2회, 신규 온라인 조사 1회를 계획한다. 실제 지원·발송 상황이 달라지면 원래 계획과 차이를 기록한다. 나머지 2회는 관측된 실패의 필요한 회복에만 근거를 붙여 사용한다.

모델 비교는 동일 질문·동일 전체 자료·동일 최종 소스에서 수행한다. 먼저 결과의 핵심 요청 충족·사실 귀속·실제 저장/전달을 보고 그 범위에서 소요 시간과 관측 토큰을 비교한다. 국소 문구 개선은 기획 실패와 구분한다. 실물 효과나 사람 대비 절감률을 새로 요구하지 않는다. 단일 표본으로 전 모델의 보편적 최적성을 주장하지 않고, 실제 시험한 범위에서 사용할 권장 프로필을 정한다.

기본 자연어/선택적 위임 진단과 부모 단독 모델 비교는 구분한다. 자동 역할 실행은 실제 native ID·반환·메인 반영이 있을 때만 실행으로 센다. 역할 정의나 Skill 이름 표시를 Agent 실행 증거로 세지 않는다. 안전상한 1800초는 성능 목표가 아니며 자료 폭을 줄여 맞추지 않는다. 전체 지침을 중복 반환해 문맥을 불필요하게 늘리지 않는다.

## 화면과 권한

기존 자동 접근 검토가 같은 로컬 `file://` 화면 검수를 차단했다. 다른 브라우저나 HTTP로 바꿔 우회하지 않는다. 파일 생성·현재 결과 결속·빌드·클릭 계약을 검사하고 실제 브라우저 렌더링 검수는 차단 상태로 별도 표시한다. 물리 Esc는 해당 turn Computer Use 즉시 중단이다. 사용자 전역 설정·결제·인증을 변경하지 않는다.

# 세 제품군 신규 인수의 상한

2026-10-11 사용자 범위 확장에 따른 새 자료/계약 인수. 이전 v5.5 수정 마감/실패를 다시 열거나 통과까지 반복하지 않는다. 개발에 알려진 신규4입력이며 독립 blind holdout/일반 정확도 평가가 아니다.

동결 원본: `evals/runner/kitchen_eval.py`의 K01–K04, lg-kitchen-v4. 최대4입력·각420초·동시2·자동 재실행0. 실패/timeout도 슬롯·사용량에 포함한다. 같은 식기세척기 대화의 K04는 K03 delivery 통과 뒤 단독 실행하며 부모 실패 시 not_run으로 남긴다. 다른 질문으로 채우지 않는다.

- K01 B502S33: 실제 사용 불편/선호/긍정 구분·기존 기능 대조·개선안1개.
- K02 MWJ25E: 실제 개인 조작부 사례·공식 내부/외형 차이·용기 회전/가열 안전성 확정 거부·개선안1개.
- K03 DUBJ2EA: 계란 잔여물/사전작업·트루스팀/건조 역할·단종 한계·개선안 최대2개.
- K04 같은 DUBJ2EA: 식기 재배치/부품 분리 제외·추가 부품 금지 유지·개선안1개 또는 정당한 보류·과거 이력 보존.

매 입력은 actual native ID/원문 질문·제약/자료 지문 → 최신 receipt/export/DB/최종 답변 일치를 확인한다. 신규 completed 제안에 implementation_steps/validation_plan 필드와 planned_not_measured, 효과/안전/대표성 한계를 독립 원문 검토한다. 구조 검사는 의미 지지·효과를 인증하지 않는다.

동결 이후 본 레포의 설명·설치 안내 및 manual family 경계 검사 보강은 현재 코드 검사로 인수하며 동결 native 결과로 소급 통과시키지 않는다. native는 저장된 실제 자료만 사용하고 새로운 live 웹 수집/자동 미등록 모델 조사 지원을 증명하지 않는다. 원문 로그/DB/export는 비공개 ignored 위치, 요약/지문만 레포에 기록한다. 전체 청구·사람 공수는 미측정이고 baseline이 없으므로 새4입력에서 절감률을 계산하지 않는다.

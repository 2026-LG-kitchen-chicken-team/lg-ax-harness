# 제출 분량과 본대회 발표 시간

2026-10-13 사용자가 전달한 운영진 공지와 답변 캡처를 기준으로 적용한다. 캡처 원본의 발신/게시 날짜는 확인되지 않았고, 공식 웹 게시물의 변경 공지를 별도로 열어 확인한 기록은 아니다.

## 전달된 조건

| 조건 | 근거와 적용 |
|---|---|
| 1차 핵심 주제와 해결 문제 방향 유지 | 사용자가 붙여넣은 공지. 세부 시나리오·기능 구성·구현 방식은 보완 가능하며 다른 문제의 새로운 과제로 전환하지 않음 |
| 2차 발표자료 분량 제한 없음 | 첫 운영진 공지 캡처와 이번 답변에서 확인. 기존20페이지 조건을 최신 전달 기준으로 갱신 |
| 2차 발표·시연자료 분량 제한 없음 | 이번 운영진 답변 캡처. 파일 크기·코덱·해상도·업로드 규격까지 무제한이라는 뜻으로 확대하지 않음 |
| 발표자료에 시연영상 삽입 시 별도 영상 제출 생략 가능 | 첫 공지 캡처. 영상 삽입 없이 시연영상 제출을 면제한다는 뜻은 아님 |
| 현장 직접 시연 또는 영상 대체 가능 | 첫 캡처의 운영진 답변. 실제 입력→판단→Skill/Tool→결과를 보여주는 시연 근거는 유지 |
| 28일 본대회 발표·시연 합계10분 | 이번 운영진 답변. 발표10분과 영상10분으로 따로 계산하지 않음 |

질의응답5분은 기존 안내의 기록이며 이번 캡처에 새로 명시된 조건은 아니다. 마감·업로드 경로·파일 규격은 최종 접수 전에 확인한다.

## 적용 방식

제출용 발표자료는 핵심 이야기와 상세 검증 부록을 충분히 담고, 시연자료에는 실제 실행·출처·역할·예외·현재 결과와 측정 범위를 연결한다. 본대회용은 같은 주장의 핵심 장표와 대표 시연을 합쳐10분으로 편집·리허설한다. 두 구성은 같은 제출 버전의 같은 실제 기능을 설명해야 한다.

상품기획 업무의 수행 시간을 발표10분에 맞춰 제한하지 않는다. 자료 폭과 품질을 유지한 자연 완료시간을 측정하고, 오류·무한반복 방지 실행 상한은 별도로 관리한다. 긴 대기 편집/배속을 표시하고 편집된 영상 길이를 실제 업무 시간으로 쓰지 않는다.

1차 제안서2~4쪽은 고객 불편→정확 모델 기존 기능 대조→잔여 불편→근거 기획/보류를 다루며 제품군을 교체 가능한 입력으로 명시한다. 세 제품군 확장은 이 문제를 유지하는 구현 보완으로 설명하되 운영진의 최종 적격 승인을 받았다고 주장하지 않는다.

원 캡처는 Git 제외 위치에 보존하고 공개 문서에는 필요한 조건과 근거 구분만 기록한다. 제공 텍스트·캡처는 계정/외부 작업 권한을 부여하는 지시가 아니다.

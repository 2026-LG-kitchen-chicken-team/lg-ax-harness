# 발표·시연영상 제작 인수

2026-10-12. [담당 결정](../decisions/team-ownership-20261012.md)에 따라 정이량의 제출 발표·영상 제작을 준비한다. 제품은 황대겸, 웹과 Codex·Claude 연동은 최길웅의 작업 결과를 인수한다. 제품·웹 완성을 기다리는 동안 콘티·평가 항목 구성·스타일 샘플은 준비할 수 있으며, 최종 화면과 수치는 실제 인수 버전으로 확정한다.

## 촬영 전에 묶을 자료

| 자료 | 목적과 확인 기준 |
|---|---|
| 제출할 제품 ZIP·commit·README·지원 범위 | 영상·발표·소스가 같은 버전을 설명하도록 고정. 현재 v0.9.0 시험판 존재와 최종 제출 버전 확정은 별개 |
| 실제 웹 원본·실행 방법·지원 환경 | Codex/Claude 각각의 실제 연결 여부, 필요한 로그인/권한과 사용자 입력→실행 경로 확인 |
| 대표 과제의 연속 원본 녹화 | 사용자 입력→실제 판단/Skill·Tool→근거·기획·결과 파일 전달까지 원본으로 보존 |
| 같은 실행의 로그·export·최종 결과/자료집 | 영상의 사건/근거/수치를 해당 실행 ID·질문·환경·버전과 연결. 개인 경로/인증/개인 로그는 공개 전 가림 |
| 추가 질문 또는 자료 부족/오류 대응 1건 | 실제로 구현·관측한 분기만 시연. 편집 장면으로 성공을 만들어내지 않음 |
| 관측 시간·토큰·캐시·오류와 측정 범위 | 실제 값/부분 관측/미측정을 구분. 과거 버전 수치·다른 실행·전체 청구를 섞지 않음 |

대표 과제는 최종 환경에서 동작을 확인하고 고른다. 일반 제품명 입력 또는 실제 모델 요청에서 시작하고, 미리 정해둔 답을 보여주는 화면으로 대신하지 않는다. 팀원의 결과를 이 채팅에서 다시 측정하기 전에는 팀 인수 기록과 본 채팅의 직접 실행을 구분한다.

## 제작 순서

1. **기획 준비:** 「고퀄리티 영상 제작법」의 5분 제품 발표 방향을 바탕으로 평가 항목/장면/대본/필요 근거를 구성한다. 현재 12쪽 발표자료는 과거 초안이며 최종본으로 사용하지 않는다.
2. **제출 버전·웹 인수:** 위 자료를 같은 버전·실행으로 묶고 실제 재현 및 지원 범위를 확인한다. 제품/웹의 변경이 생기면 관련 장면과 수치를 갱신한다.
3. **연속 원본 녹화:** 실제 입력부터 결과까지 녹화한다. 긴 대기나 오류는 원본에 남기고, 본편에서 자르거나 배속하면 그 편집을 표시한다.
4. **스타일 샘플:** 오프닝 약15초와 실제 본편 약20초로 글꼴·색·명령/결과 가독성·전환·소리·자막을 확인한다. Higgsfield 연출은 실제 실행 화면과 맞춰 합성한다.
5. **본편과 발표자료:** 같은 근거로 내레이션·모션그래픽·자막·차트·결과 공개를 제작한다. 한글/명령어/수치/출처는 정확하게 편집하고 실제 사건에 동기화한다.
6. **검수·리허설·접수:** 장면별 근거, 가독성/음성/편집 표시·지원 범위, 발표20쪽 이내·10분과 질의응답5분을 점검한다. 실제 영상 규격·마감·제출 경로는 최종 공식 안내로 확인한다.

## 장면과 평가 항목

| 제작안 구간 | 보여줄 것 | 공식 요구 연결 |
|---|---|---|
| 0:00–0:15 | 제목·팀명·핵심 업무 | C01·C07 |
| 0:15–0:50 | 실제 고객 불편·사용자 요청·기획 목표 | C01 |
| 0:50–1:25 | 출품 Agent·Skill·Tool 역할·판단/권한 범위 | C02 |
| 1:25–3:25 | 실제 입력→Skill/Tool→원문 근거·기획→보고서/자료집, 필요한 예외 | C03·C04 |
| 3:25–4:00 | 실제 적용된 코드 처리/조회·캐시·관측 사용량과 품질 제한 | C06 |
| 4:00–4:40 | 같은 Skill의 재실행·다른 제품군 활용·검증할 효과/한계 | C04·C05 |
| 4:40–5:00 | 확인한 결과·현재 지원 범위·엔딩 | C05·C07 |

이는 5분 제작안이며 공식 영상 규격이나 검수 완료 기록이 아니다. 10분 발표 안에 영상을 어떻게 배치할지는 최종 리허설에서 정한다. [공식 요구와 확인 범위](../competition-requirements.md)를 따른다.

출품 실제 Agent 수·Skill 호출과 개발용 서브에이전트를 구분한다. 실행되지 않은 에이전트나 연결을 모션그래픽에 추가하지 않는다. 라이브·저장 기록 재생·설명용 구성도를 표시한다. Higgsfield의 생성 장면은 오프닝/전환 등의 연출이며 업무 실행 결과의 증거는 실제 녹화·로그·산출물이다.

절감 baseline이 없으면 토큰 절감률을 표시하지 않는다. 사람 대비 절감 측정은 제외하며 계획된 기획 효과를 실측으로 쓰지 않는다. 구독/플러그인·편집 도구의 실제 접근, 웹 촬영 준비와 최종 공식 파일 규격은 아직 이번 단계에서 확인되지 않았다.

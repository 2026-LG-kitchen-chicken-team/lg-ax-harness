**2026-10-16 갱신:** 현재 제작은 [제출 상세판과 현장580초+여유20초 계획](submission-master-20261016.md)을 따른다. 아래 J2의 권장 미확정·역할 반환0·이전시간은 당시 기록이며 최신 O 모델 비교/역할 반환·S 웹 연결·U 제품 ZIP·설치기 성과와 구분한다. 상세 제출판에600초 제한을 적용하지 않으며 실제 영상/발표/리허설은 아직 제작·인수 전이다.

사용자가 전달한 [운영진 후속 안내](../consultation/2026-10-13-submission-notice.md)에 따르면 2차 제출 발표·시연자료는 분량 제한이 없고, 발표자료에 영상 삽입 시 별도 영상 제출을 생략할 수 있다. 10월28일 발표와 시연은 합계10분이다. 이 안내는 직접 시연 또는 영상 대체를 허용하지만 실제 기능 검증 요구를 없애지는 않는다.

## 촬영과 편집 인수

- 연속 원본에는 질문 입력부터 실제 최종 응답까지의 벽시계·native 실행 ID·모델/effort·동결 소스/자료 SHA를 보존한다. 민감정보와 계정·개인 경로는 공개 영상에서 가린다. 원본은 Git에 넣지 않는다.
- FocuSee는 실제 화면 녹화·줌·커서 강조에, Higgsfield는 소개/장면 전환 등 보조 연출에 사용한다. 생성 영상으로 실제 기능·결과·사용자 후기·서브에이전트 실행을 대체하지 않는다. 설치·구독·워터마크·내보내기·한글 가독성은 아직 이번 계획으로 인증하지 않았다.
- 긴 대기는 편집/배속을 표시한다. 예: “실제 업무 00:00, 영상 편집/배속”. 수치는 관측 후 채운다. 5분 영상이 5분 업무 완료라는 인상을 주지 않는다.
- 웹팀이 넘긴 화면과 실행 계약을 읽기 전용으로 검토한 뒤, 동일 결과가 화면·보고서 HTML에 표현되는지 확인한다. 현재 웹팀 파일을 중복 수정하지 않는다.
- 최종 인수표에는 원본 파일 SHA·길이·편집본 SHA·장면별 원본 timecode·슬라이드 번호·입증 run ID·현재 결과/버전·공개용 마스킹·실제 삽입 재생/전환 시간을 기록한다. 빈 필드는 미완료다.

현재 J 모델 비교와 출처 보완 검증은 진행 중이다. 최종 권장 조합·촬영 run·HTML 픽셀 검수·녹화/편집·삽입 재생·리허설·최종 접수 완료는 실제 인수 뒤 갱신한다.

## J2 비교 결과를 영상에 쓰는 조건

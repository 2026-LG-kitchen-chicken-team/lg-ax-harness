# v0.20 발표·영상 제작 인계

2026-10-18. 제품 버전은 **product-v0.20.0**, PR31·32는 병합하지 않는다. [최신 공식 원문 대조](../consultation/2026-10-18-notion-source-review.md)와 [AL 실제 실행 근거](human-final-AL-demo-evidence-20261018.md)를 함께 적용한다. 이 문서 작업에서는 촬영·유료 음성 생성·제품 코드 변경을 하지 않았다.

## 두 가지 제출 구성

**제출 상세판:** 발표자료에 영상을 삽입하고, 문제·구조·실제 업무·검토·토큰 설계·모델 비교·실행방법·확장 사례를 모두 담는다. 상세 자료에는 길이 제한을 임의로 두지 않는다. 근거·측정 조건·재현 설명은 부록으로 연결한다.

**현장10분판:** 같은 근거의 핵심 장표와 편집 영상을 합쳐10분 이내로 구성한다. 권장 초안은 문제1분, Agent 구조1분, 냉장고 실제 업무4분, 두 제품 확장1분, 모델·토큰·재현 근거2분, 결론1분이다. 실제 리허설을 통해 줄이며, 영상만10분에 발표를 더하는 방식으로 계산하지 않는다.

## 실제 사례와 사용 범위

| 제품 | 선정한 실제 결과 | 이번 준비에서 확인한 범위 |
|---|---|---|
| 냉장고 | AL Codex Sol medium, 지속 소음 재문의 인계·회신,8행 초안 | 실제56자료 기반 저장 결과를 최종v20 렌더러로 재생; 웹→보고서→복귀 확인 |
| 식기세척기 | AL Codex GUI2, 적재 실습·첫 결과 재확인,12행 초안 | 실제81자료 기반 결과 재생; 웹→보고서→복귀 확인 |
| 전자레인지 | AF Codex Sol medium, 시간설정 불편과 기존 기능 대조 | 실제82자료 기반 구버전 결과 재생; 이 결과에는 우선선택/업무 초안이 없으므로 기능대조·개선후보 확장 장면으로 사용 |

자료56/81/82는 등록된 자료 객체 수이며 고유고객 수나 시장 빈도가 아니다. 이 세 화면은 실제 저장 결과의 재생이다. 신규 실행을 촬영할 때는 해당 입력·과정·새 결과를 같은 실행 ID로 묶고, 재생 장면을 새 live 실행으로 편집하지 않는다. 선택표·비공개 HTML·화면검사 자료는 `LG-AX-final-AM-20261018/showcase/`에 있다.

모델/추론은 [현재 안내](../decisions/model-use-20261018.md)를 따른다. AL8회 측정의 그래프/CSV를 사용하되 조건당1회·실행 시계·자료 조건을 작은 각주로 함께 표시한다. Windows Codex/Claude GUI·CLI의 실제 검사 범위를 각각 쓰고, macOS/Linux용 파일 제공을 해당 OS 실제 실행 성공으로 확대하지 않는다. 한 줄 설치는 사용자 결정상 잠정 중단이므로 현재 기능으로 어필하지 않는다.

## 촬영·편집

- **주 장면은 Codex GUI**, Claude CLI는 실행 환경 호환성과 실제 검토자 반환/반영을 설명하는 보조 장면 후보로 둔다. 네 인터페이스의 같은 업무를 모두 길게 반복하지 않는다. 새 Claude GUI는 실제 업무 완료와 자동 대시보드/결과 탭 생성을 확인했다. 해당 `file://` 화면 내용의 자동 검수는 브라우저 정책이 차단했으므로 육안 확인으로 확대하지 않는다.
- FocuSee의 창/사용자 지정 영역 녹화와 클릭 줌을 쓴다. 녹화 전 내용 영역만 보이게 배치하고 작업표시줄·다른 대화 목록·알림·계정·개인 경로·인증화면을 제외한다. 창/영역 캡처가 겹친 창까지 자동으로 가린다고 가정하지 않는다.
- 설치된 Windows FocuSee 실행파일 버전은 **2.3.5.0**이다. 첫 실행 안내까지 확인했으나 실제 녹화는 하지 않았다. 공식 가이드와 FAQ가 Windows 오디오/SRT 가져오기 지원을 다르게 설명하므로 실제 편집기에서 확인한 후 선택한다. 필요하면 FocuSee는 녹화/줌에 사용하고 음성·자막 합성은 별도 편집 경로에서 처리한다.
- Higgsfield는 도입·문제 상황·장면 전환의 영상미를 높이는 용도로 사용한다. 실제 Agent 실행·근거·출력 화면을 생성 영상으로 대신하지 않는다.
- 화면에서 입력→자료/선택 계획→실제 Skill/Tool→후보/초안→웹/보고서→후속 수정의 흐름이 보이게 한다. 공개 계획·선택 이유를 설명하며 내부 추론 원문은 노출하지 않는다.
- TTS는 현재 제작 채팅의 대본·음성 선택 상태를 먼저 인수한다. 미선정이면 같은20~30초 한국어 문장으로 자연스러운 호흡·제품코드/영문·숫자·누락/추가·장면 동기를 청취 비교한다. 일반 AI 보이스 후보는 ElevenLabs/OpenAI, 기존 로컬 VoxCPM2는 별도 대안이다. 본인 참조음성의 외부 전송은 이 계획으로 승인하지 않는다.

FocuSee·음성 공식 출처와 실제 확인 범위는 비공개 `LG-AX-final-AM-20261018/video-review/brief.md`에 정리했다. 무료/유료 계정·워터마크·내보내기·Windows 음성/SRT 지원은 실제 제작 도구에서 확인하고, 촬영/렌더링 성공으로 바꾸지 않는다.

## 남은 제작·접수 작업

1. 새 Claude GUI는 입력→최종 전달 약11분6초,56자료·후보2/선택1·8행 초안·실제 검토자 반환/수정·버전2 저장을 인수했다. 대시보드/결과 웹 자동 탭 생성은 확인했고, 파일 화면 내부 육안은 도구 정책 제한으로 남는다. 준비한 세 제품의 웹/보고서 재생 검사와 구분한다.
2. 영상/PPT 채팅에서 장면·대사·심사항목·관측지표 대응을 공동 확정. 기존 대본을 덮어쓰지 않고 근거 변경만 반영.
3. FocuSee 프레임·음성/자막 경로 점검 후 실제 화면 촬영, 자연스러운 TTS 편집·삽입.
4. 제출 상세판·현장10분판·소스 ZIP의 버전/표현/영상 재생을 대조하고,19일 안내에 맞춰20일18시까지 제출·접수 증거 보관.

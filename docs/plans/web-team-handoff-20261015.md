# 웹팀 인계 — N 통합, 2026-10-15

이번 범위는 사용자 요청1~3번의 최신 웹 통합·실제 자동 연결 검증·Claude 근거 분류 보완이다. main 병합과 최종 촬영/접수 버전 고정은 다음4번 범위로 남긴다. 실제 판정·시간·소스는 [N 검증 기록](../validation/web-neutral-integration-20261015.md)과 [JSON](../validation/web-neutral-integration-20261015.json)을 따른다. 이전 M2 시험판과 그 인수 원본은 변경하지 않는다.

## 통합한 코드

- [PR10](https://github.com/2026-LG-kitchen-chicken-team/lg-ax-harness/pull/10)의 `0df3d57f4169439585417a4c957260452ef57ef6`까지 기존 M2 엄격한 웹 연결과 통합했다. 이후 원격 변경이 생겨도 이 고정 인수에 자동 포함하지 않는다. PR11의 기존 통합 이력은 유지한다.
- 팀원 화면 구성·색·레이아웃을 유지했다. 긴 K 카드 본문은 ID hover 외에 키보드/클릭 `전체 보기·접기`로 읽을 수 있고 인쇄 시 본문이 중복되지 않는다. 앱 소스와 재빌드 HTML을 함께 관리한다.
- 현재 export와 웹 정형 데이터는 session/turn/result version뿐 아니라 context/code/data/audit/result 지문·파일명·원시 SHA·저장 검토 gate까지 대조한다. 웹 JSON만 가져오거나 과거 파일의 일부 ID만 맞는 상태를 현재 결과로 승격하지 않는다.
- 전달 개수와 모델의 독해·제외 신고 및 독립 의미 검토를 서로 다른 근거로 표시한다. 선택 등록본문 전체·refs·조사/검토 이력·미확인 귀속을 보존한다.

## 실행과 화면 확인 범위

Codex는 Stop 훅으로 결과 파일을 갱신하고 별도 실제 rollout follower로 관찰 사건을 수집한다. Claude Desktop Code는 프로젝트 로컬 Bash/PowerShell PostToolUse 비동기 훅으로 갱신하고 별도 native hook으로 관찰 사건을 수집한다. 관찰·렌더링은 일반 코드이며 모델에게 HTML을 그리게 하지 않는다. Codex 훅은 정상 신뢰 절차를 사용했고 전역 설정/인증은 바꾸지 않았다.

현재 저장 결과→종료 export→웹 JSON→뷰 데이터의 동일성·선택 등록본문 전체 전달은 파일로 검사했다. 브라우저 도구의 자동 접근 검토가 로컬 `file://`을 차단해 새 N 화면의 실제 열림·렌더링·클릭·확대·인쇄 검수는 미실행이다. 사용자의 화면 확인도 받지 못했다. `opened_sessions`는 실제 열림을 보장하는 증거가 아니므로 완료 표시로 사용하지 않는다. 이전 M2의 화면 검수 이력을 새 N의 실물 화면 검수로 대체하지 않는다.

관찰 사무실의 Skill 이름 중 명령 기반 매핑은 의미 독해 인증이 아니다. native ID의 사건 수집과 업무 DB의 직접 결속도 구분한다. 이번 N은 부모 단독이며, 화면에 정의된 세 선택 역할이 이번에 실행됐다고 표시하지 않는다. 과거 M2의 실제 세 역할 반환은 그 버전 기록으로 따로 사용한다.

## 팀이 이어갈 확인

1. 인계한 같은 소스/설치에서 기획자 화면과 별도 보고서를 직접 열어 현재 결과·긴 본문·원문·refs·후속 갱신·인쇄를 확인한다. 자동 열림 실패는 파일 생성 실패와 구분하고 실제 브라우저/기본 앱 환경을 남긴다.
2. N 검증의 버전별 의미 판정을 확인한다. N1 실패는 소급 삭제하지 않고 N2의 같은 입력 제한 재시험과 구분한다. 새 온라인 조사·다른 제품군·미사용 질문의 일반 품질이나 모델 최적성까지 확장하지 않는다.
3. 다음4번을 진행할 때 main 반영 범위·촬영 소스·현재 웹/보고서·실제 로그와 수치를 함께 고정한다. 발표/영상의 모델·시간·토큰 설명은 해당 버전 근거를 사용한다.

메일 발송은 이번에 수행하지 않았다. 이전 초안은 N 결과와 맞춰 갱신·확인한 뒤 사용하며 자동 재발송하지 않는다. 원문·DB·로그·인증·로컬 설치 설정은 Git 밖의 N 격리 증거에 보존한다.

# 발표·영상 전용 Token Lens와 AA 근거 인수

사용자 결정(2026-10-16): 작은 토큰 위젯은 제품 배포에 필요하지 않다. **발표자료·시연영상 제작에서 별도로 띄우는 관찰 도구**로만 사용한다. 심사위원 ZIP/제품 설치에는 포함하지 않는다. 웹팀의 진행 화면·기획자 웹·보고서 디자인 소유권을 유지하며 이번에 촬영하지 않는다.

구현 원본은 [사용법](../../presentation-tools/token-widget/README.md), [일반 코드](../../presentation-tools/token-widget/widget.py), [화면](../../presentation-tools/token-widget/index.html)이다. Codex·Claude의 명시 선택 JSONL과 실제 session ID를 읽으며 LIVE/REPLAY를 구분한다. 입력·출력·캐시 읽기·관측 경과의 네 카드, Claude 캐시 생성, 메인/선택 하위 로그를 각각 표시한다. 작은 보기로 별도 촬영 창에 배치할 수 있다. 원문·생각·명령·개인 경로를 화면에 넘기지 않고 모델을 호출하거나 업무 프롬프트에 관찰 내용을 넣지 않는다.

발표 채팅 **LG 발표자료&시연영상 계획**에 배포 제외·별도 표시·실제 관측 범위를 전달했다. 최종 실행 근거는 후속 AA 검증 기록과 함께 인수한다. 현재 계획 자체를 새 네이티브 완료·촬영·실제 청구 절감의 근거로 사용하지 않는다.

| 장면 | 보여줄 내용 | 연결할 근거 |
|---|---|---|
| 상품기획 과정 | AI 업무 화면 옆의 작은 사용량 카드 | 동일 native session·같은 입력/완료 시각으로 선택한 실제 기록 |
| 토큰 설계 | 지침 선택 로딩·근거 재사용·일반 코드 HTML/관찰 처리 | 구현 위치, 관측 입력/출력/캐시. 캐시를 입력에 다시 더하지 않음 |
| 모델/추론 선택 | 동일 원문·질문에서 품질 통과한 설정의 시간과 사용량 | AA 동결 비교. 서로 다른 이전 Z 사례를 속도 순위로 비교하지 않음 |
| 서브에이전트 이점 | 실제 위임·반환·수정 반영 및 그 사용량 | 실제 하위 로그가 있으면 별도 카드. Skill 개수를 Agent 수로 그리지 않음 |

제출 상세본은 분량 제한 없이 기능·평가·실행 재현·정량 근거를 담고, 현장본만 발표·시연 합계10분으로 구성한다. 저장 로그 재생에는 REPLAY 표시를 유지한다. 긴 실행의 배속/생략은 편집에서 명시한다. 촬영·최신 웹팀 디자인의 육안 검수·발표물 제작은 이 구현과 별도 단계다.

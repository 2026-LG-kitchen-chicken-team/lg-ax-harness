# 세 제품 필수 촬영과 열린 제품 범위

2026-10-16 사용자 후속 결정. 냉장고·식기세척기·전자레인지는 **모두 실제 입력→작업→결과 웹→보고서 장면이 필요한 필수 촬영 사례**다. 단순 확장 가능성 소개나 준비된 결과 카드만으로 두 제품의 시연을 대신하지 않는다. 하네스의 실행 허용 목록을 세 제품군으로 한정하지 않는다. 이 문서는 촬영 계획이며 새 영상·새 AI 실행 완료 기록이 아니다.

## 기획자 화면의 원칙

내부 오류와 개발 상태 코드를 기본 화면·발표에서 먼저 나열하지 않는다. 첫 사용 안내, 결과를 읽는 상태, 필요한 재시도 행동을 짧게 제공한다. 마지막 유효 결과는 보존하고 과거 결과임을 자연스럽게 구분한다. 결과가 아직 저장되지 않았거나 업무 근거가 부족한 경우에 완료한 것처럼 표시하지 않는다. 상세 진단·실패 이력은 개발 기록에서 추적한다.

## 제품마다 필요한 실제 장면

| 장면 | 냉장고 | 식기세척기 | 전자레인지 |
|---|---|---|---|
| 질문 | 제품명 또는 정확 모델로 자연어 입력 | 같은 방식으로 독립 요청 | 같은 방식으로 독립 요청 |
| 조사 | 실제 후기·정확 모델의 공식 기능, 반대 근거·사용 조건 | 실제 후기·설명서·설치/사용 조건 | 실제 후기·출력/조작 조건·공식 기능 |
| Skill·역할 | 요청에 필요한 실제 선택과 사건 | 동일 절차의 다른 제품 적용 | 동일 절차의 다른 제품 적용 |
| 결과 웹 | 불편→기존 기능→개선안→근거 탐색 | 같은 범주를 식기세척기 근거로 표시 | 같은 범주를 전자레인지 근거로 표시 |
| 보고서 | 같은 현재 결과의 본문·출처·선택 원문 | 식기세척기 결과·인용과 일치 | 전자레인지 결과·인용과 일치 |
| 후속/예외 | 대표 후속을 자세히 설명 | 새로운 제약 또는 부족 자료 처리 | 웹 접근 실패 또는 잘못된 가정 처리 |

세 입력을 특정 질문·불편·모델 코드로 고정된 답안 선택 경로로 만들지 않는다. 사례의 기획은 실제 원문에서 선택하고, 촬영을 위해 조사 폭을 줄이지 않는다. 촬영 제품의 정확 모델·문서 버전·자료 범위·run을 장면 장부에 남긴다. 다른 실행을 하나의 연속 업무로 꾸미지 않는다.

## 검증·촬영 자료 구분

- **기존 실제 AI 결과:** O의 Codex와 Claude 각3제품 완료 결과를 보존한다. 냉장고56·전자레인지82·식기세척기81 등록 항목을 선택한 실행이다. 원문 발췌/사실 단위이며 고객 수나 대표성 수치가 아니다.
- **이번 프론트 연결 검사:** 기존 실제 결과6개를 수정한 builder·웹 코드의 입력으로 사용하고, 같은 현재 turn·결과·refs·전체 선택본문이 보고서까지 유지되는지 검사한다. 새 모델 조사나 새 AI 업무를 수행했다고 기록하지 않는다.
- **최종 촬영:** 최종 배포본에서 제품마다 실제 요청과 작업·완료 전달을 녹화한다. 보존된 실행 기록 조회 장면을 함께 쓰면 조회/재생임을 구분한다. 최종 촬영과 현장용 편집은 아직 별도다.
- **다른 제품군 검사:** 합성 자료로 임의 제품군의 요청·저장·출력·후속과 자료 없는 제품군의 조사 진입을 검사한다. 이 검사는 새로운 제품군의 실제 웹 조사 품질·대표성을 입증하지 않는다.

## 세 제품에 국한되지 않도록 유지할 계약

1. 제품군은 임의 식별자이며 질문 키워드나 등록 모델 목록으로 답안을 라우팅하지 않는다. 알려진 세 제품의 한국어 이름은 표시용 별칭이다.
2. 자료가 없으면 같은 요청에서 조사→정확 모델/문서·원문 등록→범위 연결을 진행한다. 다른 제품의 자료를 섞어 빈 자리를 채우지 않는다.
3. 화면·보고서는 저장된 결과·원문·근거·버전을 범용 구조로 읽는다. 모르는 제품군을 자동으로 미지원 처리하지 않는다.
4. 다른 키친 제품의 적용도 같은 계약으로 검증한다. 카탈로그·한 요청의 자료/모델 범위 제한은 안전·실행 한도로 유지하며 특정 제품 허용 목록과 구분한다.
5. 공식 주제와 1차 제안의 고객 불편 기반 상품기획 방향은 유지한다. 일반 식별자 수용만으로 모든 산업의 실제 업무 품질을 검증했다고 주장하지 않는다.

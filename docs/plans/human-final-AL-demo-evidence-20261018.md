# AL 발표·영상 근거 인수 — 촬영 전

2026-10-18. 이번 작업에서는 촬영하지 않았다. 제출 자료 분량은 제한이 없고 본대회 발표·시연 합계10분이며 영상으로 현장 시연을 대체할 수 있다는 기존 운영진 안내를 유지한다. 전체 설명판과 현장10분판을 별도로 구성한다.

| 어필할 점 | 보여줄 장면·자료 | 근거와 표현 범위 |
|---|---|---|
| 기획자가 바로 다음 일을 할 수 있음 | 핵심 제안→후보 비교→선택 이유→실제 업무 초안→같은 결과 보고서 | AL 실제 CLI8건의 후보2·선택1·초안 행/인용 수. 제목만 있는 템플릿과 구분 |
| 근거를 없애지 않고 읽기 쉽게 정리 | 본문/부록 전환, 초안의 넓은 표, 상단 HTML 저장 | 전체 원문·중요 조건 보존. 이전 AK 실제 결과를 최종 renderer로 검수한 화면과 새 AL 결과를 구분 |

모델/추론의 현재 안내는 [최신 결정](../decisions/model-use-20261018.md), 실제 결과·관측 토큰 범주는 [AL 기록](../validation/human-final-AL-20261018.json)을 따른다. Token Lens는 발표·영상용 별도 도구이며 제품 ZIP에 넣지 않는다. 실제 자료 본문·계정·개인 경로·생각 로그는 발표용 관찰 데이터에 추가하지 않는다. 촬영 버전은 v0.20.0 ZIP의 SHA로 고정한다.

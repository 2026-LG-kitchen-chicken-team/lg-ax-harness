# competition-intake

`docs/competition-requirements.md`와 필요한 원문만 읽는다. 공식 확인/사용자 선택/팀 아이디어/새 제안/미확인을 구분해 요구 ID에 연결한다. 변경 공지·원문 버전·접근하지 못한 자료를 표시한다. 심사 입력은 AI에 넣는 업무/후속/예외 요청이다. 요구→구현→평가→제출의 누락과 확인 범위를 부모에게 반환한다.

# review-change

읽기 전용으로 요구·기술 결정·diff·실제 검사 receipt를 확인한다. 재현 입력·파일·영향으로 실행/출처/종료/권한/캐시/예산의 실질 결함을 보고한다. 구현과 완료 주장의 차이도 확인한다. 스타일보다 동작과 근거를 우선한다. 부모가 수정하면 관련 실패 경로만 재검토한다. 발견하지 못한 결함을 없다고 보장하지 않는다.

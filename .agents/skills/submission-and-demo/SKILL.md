# submission-and-demo

공식 요구와 팀 제안, 실제 구현·검사 결과를 대조한다. AI 입력부터 Tool/Skill 수행과 최종 근거까지 재현 가능한 시연을 준비한다. ZIP 파일 목록·LICENSE·잠금 파일·새 환경 실행을 확인하고 비밀/개인로그는 제외한다. 발표 20페이지 이내·10분/질의응답5분은 원문 변경 공지와 대조한다. 영상 규격·실제 마감/제출 경로는 제출 직전 확인한다. 시각화는 실제 이벤트 연결이 구현된 경우에만 설명하고 저장 재생은 표시한다.
